# Unity 에디터 실행 경로 확인

2026-10-13 확인.

Unity Hub가 저장소 상위 폴더 `D:/Project/레퀴엠 랜턴 (Requiem Lantern)`를 프로젝트로 열었다. 해당 위치에 오늘 빈 Assets, 기본 Packages·ProjectSettings가 생성됐으며 Build Settings의 씬 목록이 비어 있었다. 실제 게임 자산과 패키지, Main 씬은 하위 `RequiemLantern/`에 있다.

`Open-Unity.ps1`로 하위 프로젝트를 열고 `ProjectSetup.OpenMainScene`이 `Assets/Scenes/Main.unity`를 여는 것을 에디터 로그에서 확인했다. 전체 Unity 소스 참조 컴파일을 통과했다. 실제 Unity 에디터 상단 Play 버튼을 눌러 Game 탭에 Requiem Lantern 타이틀이 나타나는 것도 확인했다. 게임 진행 완료나 재화 소비는 실행하지 않았다.

스크립트에 프로젝트 존재 검사와 Main 씬 자동 열기를 추가하고 README에 정확한 Hub 추가 경로를 표시했다. 상위 폴더에 자동 생성된 Unity 설정·캐시는 Git 제외 대상으로 지정했다. 원래 폴더는 삭제·이동하지 않았다.
