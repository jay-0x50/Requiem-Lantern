# 매 턴 새 손패·전투 집중·귀항호 항해도 검증

검증일: 2026-10-15 · Unity Windows 실제 실행 및 Chrome 플레이

## 반영

- 새 라운드마다 사용하지 않은 이전 카드도 버리고, 후보 2장을 새 ID로 추첨한다. 기존의 1스킬 3장·2스킬 2장·동기화 후 3스킬 1장 구성과 버린 카드 순환을 유지한다. 같은 스킬이 다시 나올 수 있다.
- 실제 사용 카드는 Resolve 확정 시 1회 소비하고, 남은 카드만 라운드 경계에서 폐기한다. 사망자의 잔여 카드도 만료시킨다. 연결 재사용 요청은 현재 손패에서 스킬을 찾는다.
- 실행 중 스킬 바가 전투 영역 아래로 내려간다(Unity 282px/Preview 235px). 두 인물과 접촉 효과를 맞불 때 1.10배, 타격 때 1.16배로 함께 확대한다. 점화 정보와 HP는 고정한다. 접촉 때 피해를 한 번 적용하고 효과음도 한 번 재생한다.
- 다음 계획 턴에 바를 복원한다. 취소·화면 전환은 이전 Resolve를 무효화한다. 움직임 간소화에서는 바를 즉시 후퇴·복귀시키고, 배율 1·이동 0으로 진행한다.
- 작전실을 귀항호·바다 원화와 연결된 원형 기항지 지도로 바꿨다. 완료한 곳과 다음 기항지만 노출하고, 노드 선택과 실제 진입을 구분한다. 보스는 닻 표식이다. 기존 진행·후속 대화·리플레이·보상 검증을 유지한다.
- 2-1에 귀항호 이름, 등대 귀환 신호, 연안 이동과 정박 뒤 상륙을 소개하는 4행을 추가했다. 원본 JSON에서 Catalog와 기획서를 재생성했으며, 전체 대사는 616행이다.

## 실제 Unity

최종 캡처 42장의 통합 검수에서 완료 기항지 3곳+다음 1곳과 전체 10개 기항지 지도를 확인했다. 보스 닻 표식·선택한 상륙 정보·진입과 재감상·진행 제한도 검사했다. 노드 선택만으로 보상을 지급하지 않는다.

실제 Resolve에서 전투 연출 확대, 접촉 시 HP 변경과 SFX의 1회 적용, 도크 후퇴와 다음 계획 턴 복귀를 확인했다. 후퇴 중 다른 화면으로 이동해 이전 Resolve가 새 화면을 덮지 않는지 검사했다. 움직임 간소화의 자동 진행도 완료했으며, 다음 턴에 모든 생존자의 후보 2장 ID가 교체됐다. 메인 원화·SD·다수 적·가로막기·슬롯·승리 보상 검사도 통과했다.

기존 테스트의 '장 마지막=보스', '현재 손패에 공격 카드가 반드시 존재' 가정을 수정했다. 실제 보스 여부인 Stage.IsBoss와 실제 카드 종류를 검사하며, 치유 2장도 가능한 새 규칙을 따른다. 이는 검수용 데이터 수정이다. 최종 소스·빌드·실행은 모두 통과했다.

- `Unity/16-stage-frontier.png`: 완료한 곳과 다음 기항지.
- `Unity/31-voyage-full-chart.png`: 전체 10개 항구와 귀항호.
- `Unity/06b-impact.png`, `32-focus-dock-retracted.png`: 스킬 바 후퇴와 확대한 실제 근접 타격.
- `Unity/33-focus-next-planning.png`: 복원된 계획 화면.
- `Unity/34-focus-reduced-motion.png`, `smoke-result.txt`: 간소화와 전체 결과.

## 실제 Chrome

격리 포트 8128과 별도 QA 저장으로 10개 기항지 배치와 4장의 첫 기항지만 보이는 진행 경계를 검사했다. 5열 2행에서 노드 라벨과 하단 항해 기록이 겹치지 않는다. 과거 기록을 선택해도 배의 진행 마커는 현재 기항지에 남는다. 새 배·바다 원화가 실제로 로드됐다.

3-3 실제 전투에서 세라가 리안 대신 맞불했다. 실행 중 도크는 translateY 235/opacity 0/aria-hidden=true 상태였고, 다음 턴에 복원됐다. 리안·미나토·하이델의 미사용 카드까지 모두 R1의 1/2에서 R2의 3/4로 ID가 바뀌었다. 두 인물의 전투 연출이 확대·이동하는 과정과 변환 후 공유 무기 접점을 검사했다. 신규 2-1의 첫 4줄은 대화창과 기록창에서 읽었다. 콘솔 오류는 없었다.

증거: `Browser/qa-result.json`, `map-frontier-layout.json`, `ship-dialogue.txt`, 회귀 TXT. 대표 사진은 `01-ten-ports-voyage.jpg`, `02-next-port-only.jpg`, `08-final-focus-third-enemy-b.jpg`, `06-round-two-new-hands.jpg`, `07-ship-story-introduction.jpg`다.

검수 서버는 식별 후 종료했다. 사용자 저장에 진행 수정 UI 요청을 보내지 않았고, 8127은 fresh-hands-voyage-v9로 갱신했다. 최신 Windows 실행 파일은 Builds/Windows/RequiemLantern.exe다.
