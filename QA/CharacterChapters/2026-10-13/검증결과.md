# 캐릭터 중심 메인 장 통합 검증

2026-10-13. 사용자의 ‘메인 한 장이 한 캐릭터의 이야기’ 요구에 맞춰 대본과 플레이 진입을 통합했다.

## 적용

- 1장 리안, 2장 세라, 3장 노아, 4장 하이델, 5장 미나토. 각 장은 과거·합류 이유·증오와 미련·인간 또는 군체의 결전·변화를 메인 사건으로 전개한다. 카이의 여정, 세계관의 단서, 동료들의 대화는 같은 흐름에서 진행한다.
- 메인 대본 460→610행. 5장·50스테이지·25전투, 기존 단계 식별자·편성·적·전투 설정·음악 큐·보상 식별자는 유지한다.
- 작전실의 메인 스테이지로 진행을 통일했다. 캐릭터 기록은 해당 인물의 본편 장을 안내하고 해금 제한을 지킨다. 기록실은 완료한 메인 대화만 다시 읽는다.
- 독립 캐릭터 화면·라우트·API 대본·런타임 카탈로그를 제거했다. 이전 JSON·Markdown은 개발 참고 자료로 보관하며 내보내기 도구도 Markdown만 생성한다.
- 로웬·엘렌·이브·인간 경비병의 이미지 임포트 형태를 Texture2D로 수정했다. 기존 Cubemap 설정 때문에 Unity 대화 초상화가 흰 사각형으로 표시됐다. 빌드 전에 본편 초상화·적 이미지를 실제 리소스로 확인하고, 플레이 검사에서도 인간 대화의 실제 텍스처를 확인한다.

## 검증

- Core44·Campaign16·브라우저40·전투 연출33 = 133개 규칙·회귀 검사 통과.
- 캠페인25개 전투 × 시드0·1·2 = 75회 진행 검사 통과. 장 대본과 제목 외 전투 설정은 유지했다.
- 원본 JSON과 생성된 카탈로그의 다섯 중심 인물·장 주제·대화·음악·편성 일치, 중심 인물이 장의 여섯 이상 대화 구간과 마지막 구간에 참여하는지 검사했다.
- 실제 HTTP에서 별도 캐릭터 대본이 없고 중심 장 정보·캐릭터 이름이 포함된 본편 캡션이 전달되는지 확인했다. 단계 잠금·후속 대화·첫 보상·중복 요청·재감상 검사를 통과했다.
- Unity 참조 어셈블리 소스 컴파일, 실제 Windows 개발 빌드와 격리 저장 플레이 검사 통과. 27개 실제 화면으로 다섯 중심 장 지도, 본편 인간 재회 대화, 대화 후 전투 제한, 기록실과 잠긴 인물의 본편 버튼, 기존 카드·점화·타격·보상 흐름을 확인했다.
- 브라우저 실제 UI에서 리안의 장 지도·본편 캡션, 인물 기록→같은 장 지도, 노아의 잠긴 장 안내, 완료한 본편만 표시하는 기록실과 무보상 재생을 확인했다. 긴 장 제목의 잘림과 중복 인물명 표시도 수정했다.

결과는 `Unity/smoke-result.txt`와 `Browser/qa-result.txt`에 기록한다. 검증에는 별도 저장 파일을 사용했다. 기존 사용자 진행과 재화는 수정하지 않았다.

## 현재 범위

전용 BGM의 실제 음원과 보스별 다중 페이즈는 후속 제작이다. 5-10은 1부의 문턱으로 끝나며 태양과 기억의 최종 선택을 해결하지 않는다. 이전 독립편 초안은 현재 본편과 보스명·장면 순서가 다를 수 있으며 현재 플레이 대본의 기준은 `메인스토리/campaign.json`이다.
