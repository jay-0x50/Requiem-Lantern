# 대화 읽기와 마레 연결 검증

## 구현 범위

- 자동 진행은 각 대사가 완전히 표시된 뒤 `autoDelay`만큼 기다린다. 값은 1~6초로 제한하며 기본값은 2.6초다. 수동 진행에는 대기 시간을 적용하지 않는다.
- 기록에는 현재 공개한 글자까지만 담는다. 기록 창을 열거나 창·탭을 벗어나면 타이핑과 자동 진행을 멈춘다. 닫거나 복귀하면 같은 글자 위치에서 재개하고, 완문 대기는 새로 시작한다.
- 장면 안의 인물 두 자리를 유지한다. 새 인물은 현재 줄에서 빠진 자리로 들어오고, 서술은 기존 인물을 유지한다. 청자 불투명도는 0.6이다.
- 마지막 대사에는 실제 다음 행동을 표시한다. 다시 보기의 진입·마무리 대화 경계는 ‘이어서 읽기’로 구분한다.
- 거점에는 다음 스테이지 번호·제목과 이어보기 진입을 표시한다. 항로실 진입도 유지하며 항로 상세의 명단에는 ‘등장인물’을 붙인다.
- 맞불 예상 결과에는 동료, 예고 번호, 판정 기호, 아군·적 위력을 표시한다. 허상은 실제 무피해 설명을 유지한다.
- 마레의 원화·SD 전투 시트를 연결한다. 실제 소환 확률 표에서는 `recruitable=false`인 카이를 제외하고, 기존 보유 카이의 열람·편성을 유지한다.

## 자동 검사

- `Tests/preview-regression.cjs`: 108개 통과. 공개 글자만 기록, 기록·포커스 중단과 재개, 취소된 타이머의 중복 진행 차단, 대사별 대기 제한, 80줄 기록 보존, 인물 자리 유지, 전환 문구, 이어보기, 확률 표와 기존 카이 호환, 맞불 예상 결과의 주체를 확인했다.
- `Tests/combat-fx-regression.cjs`: 49개 통과. 마레를 포함한 7개 실제 아군 시트와 보스의 양방향 맞불 14개에서 무기 접점이 일치한다. 접촉 시 HP 1회 적용·취소 복구·움직임 간소화 검사를 유지했다.
- JavaScript 구문 검사와 `git diff --check`를 통과했다.

실제 탭 숨김 검사는 제한이 있었다. CUA로 별도 빈 탭을 만들었지만 게임 탭의 `visibilityState`가 계속 `visible`이어서 자동 진행이 정상적으로 이어졌다. 따라서 이를 숨김·포커스 중단의 실제 화면 검증으로 주장하지 않는다. 해당 이벤트에서 글자 위치 보존·타이머 취소·복귀 시 새 대기를 시작하는 동작은 JS 회귀로 확인했다.

검수 중 콘솔 오류는 없었다. 최종 대본 690행으로 다시 빌드한 결과도 경고 0개, 오류 0개였다. 검수 탭과 8128 서버는 모두 종료했다.
