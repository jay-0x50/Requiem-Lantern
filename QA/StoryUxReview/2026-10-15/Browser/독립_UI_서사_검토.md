# 현재 화면의 UI·서사 검토

## 검토 기준

- 버전: `5b281bc261aa96e8d9cc5460acb24eafd698575f` / `recruitment-v12`.
- 최신 소스로 별도 빌드한 8128 서버와 복제 QA 저장 파일을 사용했다. 사용자 8127과 사용자 저장 파일은 변경하지 않았다.
- Chrome에서 타이틀 → 거점 → 항로실 → 1-4 대화를 직접 조작했다. 보스 2-8은 실제 입력으로 3라운드까지 진행해 4인 편성과 6개 예고를 확인했다.
- 모든 이미지는 이번 검토에서 새로 촬영했다. 기존 QA 이미지는 재사용하지 않았다. 아래 내용은 개선 후보이며, 코드는 변경하지 않았다.

## 관찰한 문제 5개

### 1. 거점에서 이어 볼 이야기가 구체적으로 보이지 않는다

`Screens02-main-hub.jpg`에는 ‘리안의 장’과 ‘항로실’이 보이지만, 다음 스테이지인 ‘1-4 낯선 불꽃’은 보이지 않는다. 다시 접속한 플레이어는 항로실을 열어야 어디까지 읽었는지 알 수 있다. 거점의 주 진입 버튼에 다음 스테이지 번호와 제목을 함께 표시하는 방향을 검토할 만하다.

### 2. 스테이지의 등장인물과 출격 파티를 구분하기 어렵다

`Screens03-stage-route.jpg`의 상세 패널에는 ‘카이 · 리안 · 세라’가 제목 없이 나오고, 아래에 ‘출격 리안 · 미나토 · 하이델 · 카이’가 나온다. 이야기 등장인물과 보유 캐릭터 편성을 분리한 규칙은 유지할 수 있지만, 현재 화면만 보면 서로 다른 두 명단의 의미가 불분명하다. 첫 명단에 ‘등장인물’처럼 역할을 밝히는 짧은 표기가 필요하다.

### 3. 발화자가 바뀔 때 인물의 좌우 위치도 바뀐다

1-4의 02/08에서는 리안이 왼쪽, 세라가 오른쪽에 있었다. 다음 03/08에서는 세라가 왼쪽, 리안이 오른쪽으로 바뀐다. `Screens04-dialogue-two-characters.jpg`가 03/08 장면이다. 청자 원화의 불투명도도 0.35여서 복잡한 배경에 묻힌다. 짧게 대사가 오갈수록 인물을 다시 찾게 되므로, 좌우 자리를 유지하고 발화 강조만 옮기는 방식과 청자의 밝기를 검토할 만하다.

### 4. 전투 예상 결과가 어느 맞불에 속하는지 바로 읽히지 않는다

`Screens05-combat-planning-six-intents.jpg`에는 이름 없이 ‘우세 · 기대 위력 …’로 시작하는 예상 결과가 세 줄 나온다. 동시에 6개 예고와 여러 연결선이 있어, 각 예상 결과의 아군과 적 스킬을 화면만 보고 대응하기 어렵다. 예상 결과에 아군 이름과 대상 스킬을 짧게 붙이거나 현재 선택한 맞불을 강조하면 판단이 쉬워질 것이다.

### 5. 예고와 실제 점등의 불 모양이 다르다

계획 화면의 예고 타일은 불 실루엣과 개수로 표현하지만, `Screens06-combat-clash.jpg`의 실제 점등 패널은 둥근 타원 두 개로 보인다. 같은 불 규칙을 나타내는 요소임을 연결하기 어렵고 동전이나 알처럼 읽힐 수 있다. 실제 점등 여부와 연출 시간은 유지하면서 불의 외곽 모양을 통일하는 방향을 검토할 만하다.
