# 여러 적·공격 표적·대신 맞불 검증

검증일: 2026-10-15 · Unity Windows 실제 실행 및 Chrome 플레이

## 반영

- 메인 전투25개 중 적2명7개·3명9개·단독9개를 구성했다. 첫 튜토리얼과 보스는 단독, 일반전은2~3명이다. 원본campaign.json의enemyCount에서 C# 카탈로그와 기획서를 생성한다.
- 적별 본체·부위·체력·균열·정신력·예고ID를 분리했다. 다른 적이 살아 있으면 전투를 계속하고, 사망·균열·부위파괴는 해당 적의 예고만 취소한다.
- 예고에 적 번호와 원래 표적 이름을 표시한다. 다른 동료의 공격 카드를 연결하면 가로막는 동료와 변경된 선을 표시하고 원래 표적도 남긴다.
- 단일 공격의 대신 맞불에서 지면 대신 나선 동료가 맞는다. 광역은 맞불을 이기면 막고, 지면 기존 전체 범위로 피해를 준다. 별도 속도 제한·추가 비용은 없다.
- 기존4인·8장 카드, SD·메인 원화 분리, 불·정신력·2연승·상성·물리 타격음·진행 저장을 유지한다. 작전실에서 적 수를 표시한다.
