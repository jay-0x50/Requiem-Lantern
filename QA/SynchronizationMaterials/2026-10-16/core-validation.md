## 새 기능 검증

- 캐릭터 7명의 전용 재료 이름·초상화·필요 수량이 각각 맞는지 확인했다. ★5는 10개, ★4는 6개이며 공통 등불 조각 10개도 함께 필요하다.
- 공통 재료나 해당 캐릭터 전용 재료가 1개 부족할 때, 다른 캐릭터 재료만 많을 때, 미보유 캐릭터일 때, 이미 동기화했을 때 모두 재고와 성장 상태를 그대로 유지했다.
- 실제 던전 전투로 미보유 세라의 재료 12개를 먼저 모았다. 미보유 상태에서는 동기화를 거부했으며, 획득 후 정확히 10개와 등불 조각 10개를 사용해 3스킬을 열고 남은 전용 재료 2개를 보존했다.
- 7개 채집 루트에서 seed 0·1·42를 사용해 총 21회 실제 전투 승리했다. 기본 미동기화 4인 파티(리안·미나토·하이델·마레), `Good` 판정, 실제 체력과 전투 결과를 사용했다. 결과는 `core-route-balance-runs.txt`에 남겼다.
- 기억 잠항은 본편 1-2의 후속 대화까지 마친 뒤 열린다. 승리 수령 시 선택한 전용 재료 3개만 지급하고, 실패·퇴각·중복 수령은 지급하지 않는다.
- 채집을 5회 반복해도 입장 비용과 일·주 제한이 없으며, 주간 잔향 회수의 공유 보상 3회를 소모하지 않는다. 본편 완료·최초 보상 기록과 기존 5개 재화도 바꾸지 않는다. 실제 승리·맞불·방어 기록은 의뢰에 반영한다.
- 일반 승리 수령 함수는 `material_` 전투의 보상을 지급하지 않는다. 전용 세션이 소유한 현재 승리에서만 전용 재료를 받는다.
- `LANTERN-SYNC-MATERIALS`는 기존 두 쿠폰과 독립적으로 한 번 사용할 수 있고, 7종 전용 재료를 각각 9,999,999개 지급한다. 어느 한 종류라도 보관 한도를 넘으면 모든 재고와 쿠폰 사용 기록을 그대로 유지한다.
- 던전 보상·동기화·신규 쿠폰에서 실제 저장 실패를 만든 뒤 진행 스냅샷을 복원하고, 같은 요청을 한 번만 성공시켰다. 보상 저장 실패에도 동일한 승리 세션을 유지했다.
- 신규 필드가 없는 구 저장은 전용 재료를 빈 재고로 시작한다. 이미 동기화한 단계·레벨·3스킬 개방, 기존 진행, 천장과 픽업 확정 상태는 유지했다.
- 전용 재료의 음수·중복·미등록 ID·null 항목은 저장 검증에서 거부하고 이전 정상 저장을 보존했다.

Core 검수 결과이며 실제 화면과 API 동선은 별도 통합 검수 기록에서 확인한다.
