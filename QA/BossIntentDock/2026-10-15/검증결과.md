# 보스 행동 확장과 가로 불 예고 검증

검증일: 2026-10-15 (한국 시간). 실행 버전: `boss-intent-dock-v10`.

## 적용한 규칙

- 4인 보스전은 첫 턴 4개, 다음 턴 5개, 3턴부터 6개 행동을 예고한다. 3인 보스전은 3 → 4 → 5개다. 동료가 쓰러져도 최초 출전 인원의 행동 상한을 유지한다.
- 각 행동은 해당 보스 부위에 속하며, 부위를 파괴하면 그 부위의 남은 예고를 취소한다. 두 부위가 모두 파괴되면 기존 본체 행동 하나만 남는다.
- 추가 행동은 표적을 분산한 단일 공격이다. 기존 광역·관통·허상과 튜토리얼의 동작을 유지한다.
- 적의 머리 위에 불 모양, 어둠 개수, 공격 종류, 원래 표적, 현재 맞불 담당을 가로 타일로 표시한다. 상세는 마우스 호버 또는 키보드 포커스로 연다.
- 상세 조회는 카드·배정·자원·난수를 바꾸지 않으며 드래그를 막지 않는다. 위력과 속도는 기본 수치임을 표시하고, 허상은 피해 없이 행동만 소모한다는 실제 규칙으로 안내한다.

## 검증 결과

| 항목 | 결과 |
|---|---|
| 공용 Core | 69 / 69 통과 |
| Campaign | 21 / 21 통과, 25전투 × 3개 시드 = 75회 승리 |
| Preview UI / 전투 FX | 89 / 49개 통과 |
| 후속 허상·가독성 검사 | 관련 UI 6개 재검사 통과 |
| 격리 HTTP | 4 → 5 → 6개 생성, 추가 예고의 정확한 부위·표적과 대신 맞불 확인 |
| 실제 Chrome | 6개 보스 타일·추가 행동 연결·일반 적 3명·실행 중 숨김과 복구·허상 판정 확인 |
| Unity | 최종 Windows 빌드, 실제 10장 실행 검사와 허상 드래그 1건 통과 |
| 사용자 로컬 프리뷰 | `8127`을 v10으로 갱신, 읽기 전용 버전·정적 코드 확인 |

Core의 마지막 허상 프리뷰 수정은 전체 69개 검사로 확인했다. 전투 계산을 바꾸지 않은 조회 수정이므로 앞선 75회 전투를 반복하지 않았다. 브라우저의 실제 입력 검수는 키보드 포커스와 카드 연결로 수행했고, 호버 이벤트는 격리 DOM 검사로 확인했다. Unity의 입력은 실행 중 UGUI 이벤트 경로로 검사했다. 사용자 저장 파일은 검수에 사용하지 않았다.

## 밸런스 관측

보스 24회, 141라운드 중 54라운드에서 보스 피해가 발생했고 누적 피해는 435였다. 추천 연결 사용 시 전원이 생존했으며, 평균 보스 클리어는 기존 5.96라운드에서 5.88라운드였다. 이번 변경으로 대응할 표적과 맞불 선택지는 늘었다. 맞불 승리도 공격 기회와 자원을 주기 때문에 난이도가 크게 높아졌다고 판단할 근거는 없다. HP·위력·보상·정신력과 맞불 경제는 추가로 조정하지 않았다.
