# 귀항호와 항해도 원화

2026-10-15 · built-in image_gen 제작

등대 요새의 보급선을 동료들의 연안 이동 거점 **귀항호**로 개조했다. 등대는 돌아올 불을 지키고, 귀항호는 정박지와 상륙 원정을 잇는다. 항해도는 거리·의무실·시계탑 등 내륙 임무의 동선도 포함한다. 2-1 도입에 이름과 귀환 신호를 소개하는 동료 대화 4행을 연결했다.

## 실제 저장 자산

- `RequiemLantern/Assets/Resources/Art/VoyageShip.png`: 1536×1024 RGBA. 전체 선체·돛대·등불을 포함한 오른쪽 방향 보급선 컷아웃. 완전 투명한 픽셀의 비율은 52.0%다.
- `RequiemLantern/Assets/Resources/Art/VoyageSea.png`: 1672×941 RGB. 원형 기항지와 항로를 코드로 배치할 수 있는 영야의 연안 배경.

기존 `RequiemLantern/Assets/Resources/Art/Keep.png`의 색·재료·분위기를 참고했다. 검은 선체·풍화된 목재·황동·따뜻한 항해등으로 기존 세계와 맞췄다. 기존 배경과 캐릭터 원화는 보존한다. 새 PNG는 도구의 기본 저장 경로에서 위 Resources 폴더로 복사했다.

`imagegen-prompts.json`에 최종 프롬프트 2개, 참조 이미지의 역할과 생성 출처를 기록했다. `validation.json`은 실제 크기·모드·알파를 읽은 결과다. Python은 알파 읽기와 검증 기록 작성에만 사용했고, 래스터를 편집하지 않았다.

## 화면과 진행

기항지는 5열 2행의 연결 동선으로 표시하고, 완료한 구간과 다음 구간만 노출한다. 귀항호의 진행 마커와 과거 기록 선택은 구분한다. 오른쪽 상륙 계획에서 기존의 진입·재출격·다시 읽기를 실행한다. 노드 선택만으로 진행이나 보상을 변경하지 않는다.

항해도와 전투 화면은 실제 게임 UI다. 배의 물리 조종·선내 자유 보행·별도의 항해 전투는 구현 범위에 포함하지 않는다.

## 전투 화면 참고

선택 단계와 실행 단계를 분리하고, 명령 후 맞붙는 인물에 집중하는 흐름을 [림버스 공식 시스템 소개](https://limbuscompany.com/)와 [ProjectMoon 공식 전투 소개 영상](https://www.youtube.com/watch?v=WEJfLhJ4xOA)에서 참고했다. 영상은 2022년 개발 중 소개이므로 현재 게임의 세부 수치를 판단하는 근거로 삼지 않았다. 손패·행동 제한·불·맞불 판정은 이 프로젝트의 규칙을 따른다.

실행 중 스킬 바 후퇴, 전투 연출 레이어 1.10/1.16배 확대, 접촉 순간의 짧은 정지와 반동을 적용했다. 기존 6포즈와 이동을 조합한 연출이며, 관절 리깅이나 중간 그림은 추가하지 않았다. 접촉 순간에 피해를 한 번 적용하고 효과음도 한 번 재생한다. 움직임 간소화를 지원한다.
