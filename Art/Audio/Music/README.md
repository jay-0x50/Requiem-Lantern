## 이번 생성 범위

현재 메인 스토리의 1~3장 마지막 보스전에 맞춰 **가사 없는 결전곡 3종**을 생성했다. 원본은 [04_Suno_엔딩보스_BGM_프롬프트.md](../../../기획서/04_Suno_엔딩보스_BGM_프롬프트.md)의 L2·S2·N2다. 1페이즈곡과 전투 후 여운곡은 후속 제작 대상이다.

현재 **리안·세라·노아 후보 각 2개, 총 6곡이 완성**되었다. 각 A의 MP3를 내려받아 비상업용 미리듣기 후보로 보관했으며, B는 Suno 링크로 비교할 수 있다. 작업 상태는 `generated_preview_files_ready`다. 게임의 음악 재생에는 아직 연결하지 않았다. 생성 URL·화면에서 확인한 길이·실제 입력·다운로드 기록은 [suno-generation-2026-10-14.json](suno-generation-2026-10-14.json)에 저장한다.

## 생성 입력

- Suno 화면에서 확인한 모델: `v6-mini`.
- 고급 생성의 Lyrics 입력을 비워 Instrumental 상태로 생성한다. 가사는 작성하지 않는다.
- 현재 화면에는 별도 Exclude 입력이 없어, 사람의 목소리를 배제하는 조건을 Styles에 포함한다.
- 화면의 Styles 1,000자 제한에 맞춰 원본 L2·S2·N2를 압축했다. 실제 입력은 리안 **953자**, 세라 **991자**, 노아 **995자**다. 캐릭터별 제외 조건도 Styles 끝에 반영했다. 정확한 입력은 JSON의 `styles`에 저장한다.
- 리안은 고급 모드, 세라·노아는 같은 음악 조건을 넣은 심플 모드로 생성했다. 성공한 작업의 고급 슬라이더 설정은 미확인이다. 제출 시도와 생성 당시 제목은 JSON에 남겼다.
- BPM·조성·길이·루프는 제작 목표다. 화면에 표시된 길이는 위 표에 기록했으며, 실제 BPM·조성·반복 구간은 미검수다.

## 사용 상태와 검수

현재 계정의 무료 생성 결과는 **비상업용 미리듣기 후보**다. 무료 계정 화면에서 **No Commercial Rights**를 확인했다. [Suno 공식 안내](https://help.suno.com/en/articles/13614785)에서도 무료 체험 다운로드는 개인·비상업용으로 한정한다. 이번 MP3는 로컬 감상용으로 보관하고, 생성 문서와 Suno 링크를 저장소에 기록한다. 상업적 사용 승인과 정식 게임 배포 가능 여부는 `false`로 기록했다.

이번에 체험 다운로드 세 회를 사용했다. 확인한 다운로드 횟수는 JSON에 기록했다.

아래 항목은 모두 미검수다.

- 가사뿐 아니라 합창·허밍·속삭임 등 사람의 목소리가 없는지 청취.
- 리안의 첼로·호른, 세라의 건반·기타·아코디언, 노아의 베이스 클라리넷·전자 리듬이 의도대로 구별되는지 청취.
- 검 충돌음과 전투 대사가 묻히지 않는지 게임에서 확인.
- 도입·반복·종료 구간 선정.
- 반복 경계에 무음·클릭·부자연스러운 재시작이 없는지 확인.

선정곡의 원본과 수정본은 구분해 보관한다. 다운로드한 뒤 확장자는 실제 파일 형식대로 기록하며, 파일 이름을 바꾸는 것만으로 WAV 변환이 완료되었다고 기록하지 않는다.

## 게임 연결 기준

이번에는 위 세 스테이지의 전투 진입에 대응하는 결전곡을 우선 선정한다. 현재 대본의 `_phase1`·`_phase2` MusicCue는 전투 전 대화에 존재한다. 실제 전투 중 페이즈 전환을 구현했다는 뜻은 아니다. 대화 건너뛰기·재시도에서도 해당 보스의 결전곡이 일관되게 선택되어야 한다.

전투 진입·승리·패배·이탈, 음악 음량과 음소거, 장면 변경 시 재생 중복과 정지를 확인한 뒤 연결 완료로 기록한다. 일반 전투와 중간 보스에는 이번 세 곡을 공용으로 배치하지 않는다.
