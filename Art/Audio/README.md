# 전투 효과음

짧은 금속 충돌 **챙**, 살과 가죽에 닿는 **퍽**, 무거운 타격의 **쿵**을 구분한 전투용 소리입니다. 점화음은 짧은 부싯돌 클릭과 불씨의 바스락거림으로 구성했습니다.

모든 소리는 이 프로젝트를 위해 직접 작성한 합성 코드로 생성했습니다. 외부 녹음, 음원 팩, AI 서비스 출력, 대사와 음악은 사용하지 않았습니다. 고정된 금속 공명과 대역을 제한한 잡음으로 재질을 표현하며, 주파수가 미끄러지는 레이저음은 사용하지 않습니다.

## 파일과 재생 위치

게임에 넣는 파일은 `RequiemLantern/Assets/Resources/Audio/Combat/`에 있습니다. 각 종류는 `_01`, `_02`, `_03`의 세 변형으로 구성됩니다. 파일 형식은 48kHz, 스테레오, 16비트 PCM WAV입니다.

| 파일 접두사 | 길이 | 전투에서 쓰는 순간 | 권장 재생 볼륨 |
| --- | --- | --- | --- |
| `clash` | 0.411~0.429초 | 맞불의 무기가 닿는 순간 | 0.50 |
| `hit_cut` | 0.211~0.229초 | 세라 등 베기 공격의 실제 타격 | 0.45 |
| `hit_blunt` | 0.251~0.269초 | 주먹·지팡이·일반 몸통 타격 | 0.52 |
| `hit_heavy` | 0.381~0.399초 | 리안의 방패 타격과 강한 일격 | 0.58 |
| `swing` | 0.201~0.219초 | 무기를 휘두르기 시작할 때 | 0.18 |
| `brace` | 0.261~0.279초 | 방어·자세 고정 | 0.34 |
| `ignite` | 0.121~0.139초 | 불 하나의 상태를 공개할 때 | 0.20 |
| `break` | 0.591~0.609초 | 부위 파괴·균열 붕괴 | 0.48 |

권장 볼륨은 마스터 볼륨을 곱하기 전 기준입니다. 타격음은 실제 접촉 시점에 한 번만 재생합니다. 맞불에서 여러 번 부딪칠 때는 변형을 순서대로 돌려 같은 소리가 연달아 반복되는 느낌을 줄입니다. `clash`와 실제 `hit_*`는 서로 다른 사건입니다.

## 재생성 및 검사

필요한 라이브러리는 NumPy입니다. 저장 위치는 실행 디렉터리와 관계없이 스크립트 위치를 기준으로 계산합니다.

```text
python Tools/generate-combat-audio.py
python Tools/generate-combat-audio.py --check
```

마스터 시드는 `20261013`이며 각 파일의 시드, 길이, 최고 진폭, RMS, DC 오프셋, PCM SHA-256은 게임 리소스 폴더의 `manifest.json`에 기록합니다. `--check`는 소스에서 다시 생성한 PCM을 저장된 WAV와 비교하고 다음 항목을 검사합니다.

- 스테레오 48kHz/16비트 PCM 형식
- 클리핑 없음, 최고 진폭 0.88 이하
- 무음에 가까운 출력 없음
- DC 오프셋 0.0001 미만
- 시작과 끝의 진폭 0
- 각 종류의 세 변형이 서로 다름
- 소스와 저장된 PCM이 일치함

생성 당시 24개 파일 전부 통과했습니다. 실제 최고 진폭은 0.800012이며 가장 작은 전체 RMS는 0.037318입니다.
