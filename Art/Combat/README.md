# 전투 포즈 아틀라스

## 파일
실제 게임 리소스는 `RequiemLantern/Assets/Resources/Combat/`에 있습니다.

| 캐릭터 | PNG | 기준 몸 높이 |
|---|---|---:|
| 리안 | LianActions.png | 400 px |
| 세라 | SeraActions.png | 360 px |
| 분노의 허물 | AngerActions.png | 400 px |
| 미나토 | MinatoActions.png | 480 px |

모두 1536×1024 RGBA입니다. 원본 외형을 참조해 built-in image_gen으로 만든 6개 전투 키포즈입니다. 전신 일러스트를 이동한 효과가 아니라 팔·다리·몸통·무기 자세가 다른 그림입니다. 원본 파일은 보존했습니다. 미나토는 기존 의료 랜턴을 사용하며 지팡이를 추가하지 않았습니다.

순서는 위쪽 왼쪽부터 0 대기, 1 예비 동작, 2 공격, 아래쪽 왼쪽부터 3 후속 동작, 4 회복/복귀, 5 피격입니다. 리안·세라·미나토는 오른쪽 공격, 분노는 왼쪽 공격입니다.

## 재생 좌표
함께 제공한 `{Name}ActionsLayout.json`을 사용해야 합니다. 생성 결과가 완전히 균등한 셀을 따르지 않아 일부 검끝과 랜턴이 512px 경계를 넘습니다. 각 JSON의 표시 사각형을 사용하면 모든 신체와 무기가 잘리지 않습니다.

- `x,y,width,height`: PNG 전체의 왼쪽 위 기준 프레임 사각형입니다.
- `footX,footY`: PNG 전체의 왼쪽 위 기준 발 기준점입니다. 프레임 내부 좌표가 아닙니다.
- `bodyHeight`: 대기 자세의 머리~발 높이입니다. 프레임마다 같은 배율을 유지하십시오. 자세별 bbox에 맞춰 따로 확대하면 몸 크기가 변합니다.
- `contactX,contactY`: 공격/후속 자세의 무기 또는 주먹 접점 참고값입니다. 세라는 대각선 아래로 베기 때문에 리안의 수평 찌르기보다 접점이 낮습니다.

Unity UV는 `(x/W, 1-(y+height)/H, width/W, height/H)`입니다.
Unity pivot은 `((footX-x)/width, 1-(footY-y)/height)`입니다.
화면 배율은 `원하는 몸 높이 / bodyHeight`이며, 표시 크기는 `(width,height) × 화면 배율`입니다.

## 확인
`validation.json`에 읽기 전용 알파/사각형/발 좌표 검증 결과가 있습니다. 24개 표시 영역 경계의 알파 최댓값은 0 또는 1/255이며, 신체나 무기가 경계를 통과하지 않습니다. 원본 PNG 알파 범위는 0~254이고 완전 투명 픽셀 비율은 56~73%입니다. 생성 이미지의 RGB에는 배경색이 남아 있으므로 알파를 버리면 회색/붉은색 배경처럼 보입니다. 게임에서 RGBA 알파 블렌딩으로 표시해야 합니다.

6개 핵심 자세를 연결하는 방식이며, 촘촘한 중간 프레임이나 팔/무기별 스켈레톤 리그는 포함하지 않습니다. 생성 과정에서 의상 장식의 세부선과 얼굴은 원본과 조금 달라질 수 있습니다. 최종 전투 타격감은 재생 시간, 접촉 위치, 타격 정지, 충돌 음향과 함께 확인해야 합니다.

`imagegen-prompts.json`은 생성 프롬프트와 출처 파일 경로입니다. Python은 알파와 좌표 읽기/검증에만 사용했으며 래스터 편집이나 배경 제거에는 사용하지 않았습니다.
