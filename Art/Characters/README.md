# 캐릭터 에셋 v0.1

## 범위

기획서와 제공된 일곱 명의 원화를 토대로 만든 **정면용 2.5D 일러스트 리그**다. 원화 한 장을 투명한 평면 메시에 매핑하여 미세하게 변형한다. 옆면·뒷면이 있는 3D 캐릭터, 파츠별로 분리된 Live2D 원화, 전투용 전신 모션은 아직 아니다.

| ID | 캐릭터 | 설정 역할 | 기준 키 |
|---|---|---|---|
| kai | 카이 | 등불지기 | 168 cm |
| lian | 리안 | 광휘 · 수호자 | 172 cm |
| sera | 세라 | 화염 · 돌격수 | 163 cm |
| minato | 미나토 | 물결 · 치유사 | 158 cm |
| noa | 노아 | 그림자 · 조율사 | 176 cm |
| heidel | 하이델 | 서리 · 사수 | 152 cm |

키는 이미지 프롬프트집 2.0.1의 가안을 사용했다. 원화의 투명 여백과 자세 차이가 있어 리그 캔버스 기준의 근사치다.

## 파일

- `Cutouts/{id}.png`: 1086×1448 RGBA. built-in imagegen으로 회색 배경을 추출한 버전. 스토리 대화와 캐릭터 화면에서 바로 사용할 수 있다.
- `IdleFrames/{id}/{id}_idle_00.png` ~ `07.png`: Blender Idle 액션을 12 프레임 간격으로 샘플링한 384×512 투명 렌더. 8장 전체가 4초다. 빠른 시각 검수용이며 실제 24fps 애니메이션은 Blender 액션을 다시 렌더한다.
- `../Blender/requiem_lantern_cast.blend`: 일곱 리그와 21개 액션, 텍스처와 한글 폰트를 포함한 작업 파일.
- `../Blender/Preview/cast_presentation.png`: 이름·역할·키가 표시된 일곱 명 작업 보드.
- `../Blender/Preview/{id}_idle_01.png`: 768×1024 개별 캐릭터 시험 렌더.
- `../Blender/validation.json`: 저장한 `.blend`를 다시 열어 검사한 결과.
- `imagegen-prompts.json`: 생성 모드, 원본 경로, 요청 프롬프트 기록.

## Unity 연결

1. 사용할 Cutouts PNG를 Unity `Assets` 아래에 복사한다.
2. Texture Type은 Sprite (2D and UI), Sprite Mode는 Single, Alpha Is Transparency는 활성화한다. UI 표시에는 sRGB를 유지한다.
3. VN 화면에는 Preserve Aspect를 적용한다. 현재 원화에서 얼굴 위치와 키가 서로 다르므로 캐릭터별 표시 위치를 데이터로 관리한다.
4. 전신 바닥 기준 배치에는 하단 중앙 피벗을 기본으로 쓴다. 컷아웃 캔버스에 여백이 있으므로 실제 발 위치를 따로 조정한다.
5. 원본 이미지는 변경하지 않았다. 이 폴더의 파일 교체만으로 이후 원화 수정에 대응할 수 있다.

## 알려진 차이와 후속 제작

- 원본은 레이어가 없는 한 장짜리 일러스트다. 독립적인 머리카락·눈·입·팔·무기 리깅, 눈 깜박임과 립싱크는 파츠 분리 및 가려진 부분의 보완 원화가 필요하다.
- 미나토 원화의 체형은 프롬프트집의 '통통한 체형'보다 날씬하다. 이번 버전은 제공된 원화 외형을 유지했다. 하이델을 포함한 체형 차이는 설정표와 함께 후속 원화에서 검토한다.
- 이미지 생성 도구의 배경 추출 과정에서 미세한 선·명암·얼굴 표현이 달라질 수 있다. 완전한 픽셀 보존으로 간주하면 안 된다. 투명 경계의 잔여 색과 얇은 사슬·머리카락은 출시 전에 밝은 배경과 어두운 배경 양쪽에서 추가 마감한다.
- 리그의 공명/피격은 작은 자세 반응이다. 무기 휘두르기·달리기·옆 방향 전투 모션은 포함하지 않는다.
- 제공된 프롬프트집이 원화를 컨셉/내부 참고용으로 정의하므로 현재 결과도 프로토타입 아트다.
