# Requiem Lantern Figma v0.2

[Figma 디자인 파일 열기](https://www.figma.com/design/sfJ0Y0xC2vr4UsEtJ97OYC?node-id=4-2)

기획서 v0.2와 스토리 설정집을 바탕으로 작성한 1920×1080 가로 화면입니다. 한국어 텍스트, 전투 선, 패널, 버튼, 지도 노드는 Figma에서 편집할 수 있습니다. 사용자 제공 원화와 원화에서 분리한 투명 캐릭터, 새 배경을 사용했습니다.

## 화면

| 화면 | 노드 | 내용 |
|---|---|---|
| 타이틀 | `4:2` | 카이, 마지막 불씨, 시작 버튼 |
| 등대 요새 | `4:24` | 리안, 제1장 이야기, 첫 식사, 출격 |
| 스토리 | `4:65` | 설정집의 리안 첫 대사, 기록·자동·건너뛰기 배치 |
| 잔영 기록 | `5:5` | 리안 프로필, 유대, 다섯 동료 목록 |
| 출격 | `5:50` | 5개 이야기 노드, 파티 및 첫 발견 정보 |
| 연광 전투 | `5:100` | 예고선·맞불·2슬롯·불씨·등불·어둠도 |
| 캐릭터 보드 | `5:184` | 카이·리안·세라·미나토·노아·하이델·오르페 |

타이틀 → 거점 → 스토리/출격 → 전투와 하단 탐색에 클릭 연결 15개를 설정했습니다. 전투의 드래그·점화 판정은 Unity 구현 대상이며 Figma에서는 연결 단계의 화면 설계를 보여 줍니다.

- 본문: `#E7DCC9`, 보조 글자 `#9CA7B5`
- 등불: 기획 문서의 앰버 `#F2A541`
- 속성: 광휘 `#FFE29A`, 화염 `#E77A5D`, 물결 `#75C8C4`, 그림자 `#B09BD8`, 서리 `#A7D4E9`

- Primary / Secondary / Disabled 버튼 컴포넌트, 29개 변수, 6개 텍스트 스타일

## 검증과 남은 확인

7개 프레임을 실제 Figma 스크린샷으로 검수했습니다. 생성 결과에서 1920×1080 크기와 Noto Sans KR / Noto Serif KR 사용을 확인했습니다. 원화 7장의 이미지 해시와 모든 생성·수정 노드 ID는 `design-state.json`에 기록했습니다.

검수 후 출격 패널의 두 줄 설명 높이를 84px로 수정했고, 타이틀 및 스토리의 가로 그라데이션을 화면 전체 너비로 넓혔습니다. 이 수정은 Figma API 성공 응답과 반환된 치수로 확인했습니다. 이후 Starter 플랜의 Figma MCP 호출 한도에 도달하여 **수정 후 세 화면 재촬영과 최종 일괄 감사는 실행되지 못했습니다.**

- `02-beacon-keep.png`, `04-character-archive.png`, `06-link-battle.png`, `07-character-board.png`: 최종 상태와 같은 검수 이미지
- `01-title-before-final-fade.png`, `03-story-before-final-fade.png`: 마지막 그라데이션 수정 직전 검수 이미지
- `05-expedition-before-spacing-fix.png`: 설명 줄 간격 수정 직전 검수 이미지

분노 개체는 편집 가능한 임시 전투 실루엣입니다. 실제 적 원화와 분리 리깅 작업 때 교체해야 합니다. 출격 노드 이름·균열 수치·체력·배율은 화면 설계를 위한 예시이며, 밸런스 확정값으로 보지 않습니다.

## 수정 작업

`01-foundations.js`~`05-polish.js`는 이번 Figma 작성에 사용한 Plugin API 스크립트입니다. `02-common.js`는 화면 스크립트 앞에 붙이는 공통 함수입니다. 이미 작성된 파일에 전체 스크립트를 다시 실행하면 중복 리소스가 생길 수 있으므로 후속 작업은 `design-state.json`의 실제 노드 ID로 필요한 부분만 수정합니다.

UI 요소·캐릭터·배경은 개별 레이어입니다. 이미지 파일 한 장으로 평탄화하지 않았습니다. 원본 원화 참조와 투명 캐릭터 참조는 화면 프레임 아래에 함께 보관했습니다.
