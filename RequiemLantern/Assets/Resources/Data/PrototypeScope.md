# 연광 전투 0.1 구현 범위

## 근거 문서

- `기획서/01_게임기획서.md` v0.2: 4.2 연광 전투, 4.3 캐릭터, 4.4 거점, 8.4 결정론적 전투·연출 분리.
- `기획서/02_스토리설정집.md` v0.1.1: 프롤로그 「마지막 불씨」, 제1장 「꺼진 등대」, 8절 대사 샘플.

프롤로그의 카이 각성 → 부정 습격 → 리안의 구출 → 첫 등불 해방은 VN 요약으로 제공한다. 조작 가능한 전투는 제1장 분노 개체의 등대 요새 습격이다. 리안·세라·미나토의 합류 순서와 첫 식사 대사를 보존한다. 원문에 없는 연결 서술은 `StoryLine.IsPrototype=true`로 표시하며, 후반부 설정의 비밀은 프롤로그에 노출하지 않는다.

## 구현

- 순수 C# 전투 모델, 속도순 실행, 이벤트 목록. Unity와 브라우저 시연이 동일 코드를 사용한다.
- 캐릭터당 2슬롯, 서포트 1슬롯, 고조 2슬롯 점유, 원자적인 연결 교체·불씨 검증.
- 예고선 공개, 공격·맞불·호위·지원, 부위 지정, 사라진 맞불 대상의 본체 공격 전환.
- 타점별 파워 비교 → 속도 동률 판정 → 남은 타점 명중. 일반·광역·관통·허상선의 기본 처리.
- 부위 파괴·처치·균열로 행동 취소. 균열 직후와 다음 라운드 행동 불가, 받는 피해 +30%.
- 불씨, 등불 게이지, 어둠도, 등불 해방. 스킬별 점화 판정, 점화 연쇄, 판정 창 보정.
- 5속성 상성과 파쇄·증기·결빙·정화·잠식의 전투 효과. 결빙 이후 행동의 속도 재정렬.
- 위협도와 맞불 승산, 부상 치유, 남은 부위 압박에 따라 추천. 추천 이유를 각 연결에 저장.
- 승리·패배·새 전투, 첫 클리어와 반복 보상, 중복 보상 방지, 중앙 등탑 3단계 복구.
- 버전이 있는 XML 저장과 백업 복구. 지원되는 파일시스템에서는 원자적 교체, 제한된 Windows 환경에서는 백업을 먼저 남긴 뒤 교체.

## 이번 프로토타입의 임시 결정

기획서가 상세 룰북·밸런스 시트를 후속 작업으로 남긴 부분은 아래와 같이 정했다. 정식 확정 규칙으로 취급하지 않는다.

| 미정·혼재 지점 | 이번 적용 |
|---|---|
| 파워와 속도가 모두 동률인 타점 | 양쪽 타점을 상쇄하고 피해 없음 |
| 맞불 전체의 승리 정의 | 실제 명중 타점이 상대보다 많으면 승리 자원 지급. 타점별 지급 아님 |
| 불씨 회복이 정리 / 시작 두 곳에 기재됨 | 첫 라운드 3개로 시작, 이후 정리에 한 번만 +3. 어둠도 3은 +2 |
| 균열 피해 증가의 정확한 해제 경계 | 깨진 라운드와 행동을 쉬는 다음 라운드까지 +30%, 그 다음 관측에서 게이지 복구 |
| 피해 계산식의 계수 미정 | `max(1, 공격력 × 파워 / 10 − 방어)`에 호위·균열 보정 후 반올림 |
| 호위 피해 경감률 미정 | 35% 감소. 관통선은 호위 무시, 광역선은 전체 명중 |
| 광휘·그림자 동시 반응 우선순위 | 정화 우선 |
| 잠식의 불씨 환산·소수 처리 미정 | 반응 1회에 +1, 라운드당 최대 +1 |
| 파워·HP·보상·시설 비용 상세 미정 | `PrototypeData.cs`와 `ProgressService.cs`의 수치는 전부 임시 밸런스 |
| 스토리의 강제 패배와 3~4개 튜토리얼 전투 | 이번에는 VN으로 요약하고 분노전 한 개로 전투 핵심 검증 |

## 남은 작업

연쇄 예고선, 보스 다중 페이즈, 거래 제안, 타점 흡수, 상태이상 해제 목록, 캐릭터별 패시브, 적 AI 데이터 테이블, 전술 프리셋 저장, 4인+별도 서포트 편성 UI, 실제 프롤로그 강제 패배 전투, Yarn/Ink 편집 파이프라인, 스킬별 개별 연출, 스토리 중간 위치 저장은 이번 범위에 포함하지 않는다. 현재 데이터 원본은 `PrototypeData.cs` / `StoryCatalog`이며 향후 ScriptableObject·JSON 콘텐츠 로더로 옮길 수 있게 전투 모델과 분리했다.

## 검증

루트에서 `dotnet run --project Tests/CoreTests.csproj`.

24개 회귀 검증: 슬롯·예산, 타점·동률, 스킬별 점화, 광역·호위·관통, 부위·균열 취소, 회복·어둠도·등불·공명, 승패·재시작, 보상·복구·세이브 손상 복구, 스토리 출처 표시. 동일 오토 입력 101회가 동일한 로그를 만들며, 양호 판정만으로 4라운드에 3명 생존 승리한다. 이는 임시 밸런스의 동작 검증이며 재미·성능·기기 QA를 대신하지 않는다.
