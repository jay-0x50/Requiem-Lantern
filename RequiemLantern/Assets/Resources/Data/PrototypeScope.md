# 연광 전투와 메인 캠페인 구현 범위

2026-10-15 갱신. 상세 규칙은 기획서/07_정신력_불꽃_맞불_동기화.md, 대본은 기획서/06_메인스토리_장과_스테이지.md를 따른다.

## 현재 구현

- 5장·50스테이지·616행 대본. 스토리25·전투7·혼합18개, 순차 해금과 완료 기록·다시 읽기.
- 파티 정원4명. 기본전투는 리안·세라·미나토·노아, 메인2-4부터 모든전투4명이다. 초기6전투는 합류에 따라1~3명을 사용한다.
- 일반전은 적2~3명, 첫 튜토리얼과 보스전은1명이다. 적별 독립HP·부위·균열·정신력·예고선을 사용하고 모든 적을 쓰러뜨려야 승리한다. 적 수는 원본campaign.json의enemyCount에서 생성한다.
- 예고 카드에 적 번호와 원래 공격 표적을 표시한다. 다른 동료의 공격 스킬을 그 예고에 연결하면 대신 맞불을 걸고 선·표시가 바뀐다. 단일 공격 맞불을 지면 대신 나선 동료가 맞으며 광역 패배는 전원 피해다.
- 혼합 스테이지는 전투 전 대화, 승리, 후속 대화까지 완료해야 다음 구간이 열린다. 승리 후 종료했다면 후속 대화부터 이어진다.
- 메인 한 장이 캐릭터 한 명의 이야기다. 1장 리안·2장 세라·3장 노아·4장 하이델·5장 미나토로 명시하며 별도 개인편 메뉴와 런타임 카탈로그를 사용하지 않는다. 캐릭터 화면은 해당 메인 장으로 안내한다.
- 장마다 중심 인물의 과거에 합류·식사·원정 준비·의견 충돌·다른 동료의 대화를 엮는다. 인간과 군체 보스가 함께 등장한다.
- Unity와 브라우저가 같은 순수 C# Core로 전투·진행·저장을 계산한다.
- 정신력0 시작, -20~+20, 불 점화 확률50%+2%×정신력. 적도 같은 규칙의 어둠을 판정한다.
- 스킬은 기본 위력+켜진 불×불 위력. 매 맞불 비교에서 다시 점화하고, 2연승 후 마지막 위력으로 한 번 공격한다. 비교와 동률에는 피해가 없다.
- 속도는 행동 순서를 정한다. 동률은 연승을 초기화한다. 64회 비교의 교착은 피해 없이 종료한다.
- 5명의 1·2·3스킬과 방어 행동, 캐릭터별 동기화 저장. 등불 조각10개로 동기화1을 열면 3스킬이 개방된다. 레벨은 별도 값이며 현재1이다.
- 캐릭터별 덱은1스킬3장·2스킬2장·동기화후3스킬1장이다. 매턴미사용카드까지모두버리고 새ID의후보2장을추첨한다. 남은덱을쓰고 부족하면버린카드를섞는다. 같은스킬재등장가능. 방어행동은별도다.
- 행동은 전원1개로 시작해 매턴파티순서대로한명씩두번째를연다. 일반R1~R5는1111→2111→2211→2221→2222, 보스는R3이후2211상한이다. 전투불능으로순번을당기지않고 재시작은R1로돌린다.
- 모든실캐릭터1·2·3스킬과방어행동은각1행동이다. S3불씨·위력·동기화는유지한다. 후보카드2장은유지하고 현재행동수만큼사용한다. 잠긴두번째행동은UI·서버·추천·재사용모두차단한다.
- 작전실에는 완료한 구간과 진행 가능한 다음 스테이지만 표시한다. 기록실은 완료한 이야기만 표시한다.
- 불 결과를 하나씩 공개하고 접전 점화는 라운드당2번까지 늘린다. 스킬별 준비·궤적·되돌아 베기·반동을 구분한다. 피해는 접촉 순간 한 번 적용한다.
- 턴별행동수와불씨6·등불·상성·어둠도·부위파괴·균열·속성반응을사용한다. 잠긴스킬은입력과추천에서제외한다.
- 방어·회피·반격은 일반 예고선을 보호한다. 관통·광역과 패배한 맞불에는 개입하지 않는다. 방어 경감은 최대85%, 회피와 반격은 행동당1회다.
- 보상 중복 방지, 등대3단계 복구, XML 저장·백업 복구, 기존 저장 파일 호환.
- 공유 전투 WAV 8종×3변형을 사용한다. 금속 맞불·베기·둔기·강타·바람·장비·불씨·파괴를 분리하며 접촉음은 실제 타격 순간 한 번 재생한다. 음소거·취소는 남은 소리를 멈추고 최대8개 소리의 합산 볼륨을 제한한다.
- 리안·세라·미나토·노아·하이델은 전투전용SD6포즈를 사용한다. 원화는 메인·대화·초상에 유지한다. 분노는 기존6포즈, 인간적은 자기 일러스트의 이동·기울임·반동으로 전투한다.
- 실행중스킬바는아래로후퇴하고 맞붙는공연레이어만확대한다. 접촉정지·반동·피해시점을유지하며 다음계획턴·취소시바와배율을복원한다. 움직임간소화는확대·전환을생략한다.
- 귀항호항해도는완료+다음기항지만연결하고 선택상세에서기존스테이지로진입한다. 등대는귀환거점,배는연안이동거점이다. 내륙임무는정박후상륙동선으로포함한다. 2-1대화4행과새배/바다원화를추가했다.

## 초기 밸런스

위력·확률·정신력 증감·HP·동기화 비용은 변경 가능한 초기 수치다. 맞불 승리 정신력+2, 패배-2, 동료 전투불능 시 다른 생존 아군-3이다. 상성1.2/0.85, 수동 타이밍1.25/1/0.75와 기존 점화 연쇄 보정을 적용한다. 동일 시드·같은 입력은 같은 전투 이벤트를 재현하며 미리보기는 난수를 소비하지 않는다.

일반 첫 승리는 코인40·등불 조각2, 보스 첫 승리는 코인120·등불 조각10·기억1이다. 스토리 전용과 다시 읽기는 전투 보상을 지급하지 않는다. 기존 분노전의 저장 식별자는 유지해 중복 첫 보상을 막는다.

## 후속 제작

보스별 고유 다중 페이즈, 전용 BGM 실제 음원 연결, 추가 동기화·레벨업, 세부 중간 포즈·관절 리깅, 정식 보이스, 대화 중간 저장, 자유 편성 UI, 소환·계정·모바일 최적화가 남아 있다. 캐릭터별 BGM 프롬프트와 대본 음악 큐는 제작 자료이며 실제 음원이 아니다.
