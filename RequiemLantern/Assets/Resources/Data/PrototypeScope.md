# 연광 전투와 메인 캠페인 구현 범위

## 현재 구현

- 7명 전투 스킬은 실제 실행마다 짧은 자막을 사용하고, 3스킬은 인물별 대사·초상 컷인·무기 동작을 구분한다. 대사 순환은 전투와 카드 난수에서 분리하며 취소·허상은 실행 대사를 표시하지 않는다. 추가 동작은 피해를 중복 계산하지 않고 실제 피해 이벤트의 접촉 때 한 번 체력을 반영한다.
- 리안은 방어 실행·맞불 승리, 세라는 실제 체력 피해를 준 공격, 노아는 맞불 승리로 각성 스택을 최대 3개 모은다. 실제 3스킬 실행 시 모두 소비해 해당 행동만 기본 위력 +4·불 위력 +1로 강화한다. 각성 행동에서는 스택을 다시 얻지 않으며 맞불 패배에도 실제 사용한 스택은 소비한다. 취소·허상·계획·미리보기는 소비하지 않는다.
- 리안 3스킬은 아군 지원 시 보호막 18·정신력 +2, 각성 지원은 30·+4다. 카이 2스킬은 아군 지원 시 다음 공격 기본 위력 +3·정신력 +2다. 미나토 2스킬은 치유·정신력 +2, 3스킬은 치유·보호막 12·정신력 +3이다. 보호막은 방어 후 피해를 흡수하고 최대 40 안에서 큰 값으로 갱신한다. 공격 강화는 다음 유효 공격 전체에 적용한 뒤 한 번만 소비한다. 이 상태는 전투 중에만 유지하며 재시작과 새 전투에서 초기화한다.
- 캐릭터별 전용 동기화 재료 7종과 기억 잠항을 지원한다. 본편 1-2 후속 이야기 완료 후 목표 재료를 선택해 현재 편성 4인으로 적 2명과 싸운다. 승리 수령당 전용 재료 3개를 확정 지급하며 횟수 제한과 재화 소모 없이 반복한다. 미보유 인물의 재료도 미리 모을 수 있다. 수령 승리는 의뢰에 집계하고 잔향 회수 주간 횟수와 본편 완료에는 영향을 주지 않는다.
- 새 테스트 쿠폰 LANTERN-SYNC-MATERIALS는 기존 쿠폰과 독립적으로 전용 재료 7종을 각각 9,999,999개 지급한다. 한 재료라도 보관 한도를 넘으면 전체 지급을 취소하고, 저장 실패는 재고와 사용 기록을 함께 복원한다.
- 보급 게시판은 일일4개·주간4개 의뢰와 직접 수령을 지원한다. KST 매일05시/월요일05시 초기화이며 기간키는 단조 증가해 역행한 기기 시각으로 지난 보상을 다시 열지 않는다. 실제 본편·보상 원정의 승리 수령 때만 맞불/방어 실행 수를 누적한다. 일일 별가루160·주간640을 얻는다.
- 잔향 회수는 본편 1-2 후속 대화까지 완료한 뒤 열린다. 적 2명·3명·보스 1명의 세 난도가 주간 보상 3회를 공유하며 수령 시점에만 차감한다. 난도별 별가루 80/100/120과 코인·등불 조각·기억의 파편·캐릭터 조각 등 재료를 지급한다. 패배·퇴각은 차감하지 않고 소진 후 연습은 보상과 의뢰 진행이 없다. 본편 완료와 최초 보상 기록에는 영향을 주지 않는다.
- 퀘스트·던전·본편 보상 저장 실패는 재화·진행·캠페인 단계를 복원해 동일한 승리에서 재시도한다. 미수령 승리에서 이동할 때도 먼저 수령을 저장한다. 로컬 저장·기기 UTC 시각이 기준이며 계정 서버 시각·우편·등유 소모는 후속 범위다.

- 타이틀은 저장 여부와 무관한 ‘화면을 클릭해 시작 / CLICK TO START’ 화면이다. 일반 화면 클릭과 Enter·Space를 지원하며 설정은 별도 버튼이다. 최초 시작과 기존 진행의 진입 경로·저장 데이터는 유지한다.
- 5장·50스테이지·690행 대본. 스토리25·전투7·혼합18개, 순차 해금과 완료 기록·다시 읽기.
- 파티 정원4명. 기본 지급은 리안★5, 미나토·하이델·마레★4다. 실제 전투는 저장된 소유·4인편성을 사용하며 스토리 출연/합류와 분리한다. 세라·노아는 모집으로 획득한다.
- 리안·세라·노아 픽업: 기본★5확률0.8%,★5중픽업50%,80회천장,비픽업후다음★5픽업확정. 배너간천장/보증승계,1회별가루160개,10회1600개. 중복은★4/5공용조각20/100개다.
- 거점설정쿠폰 LANTERN-TEST-9999999는별가루/코인각9999999, LANTERN-MATERIALS는등불/기억/캐릭터조각각9999999를저장당1회지급한다. 모집/쿠폰/편성은저장실패시난수까지복원하며이전클리어/성장/재화를보존한다.
- 일반전은 적2~3명, 첫 튜토리얼과 보스전은1명이다. 적별 독립HP·부위·균열·정신력·예고선을 사용하고 모든 적을 쓰러뜨려야 승리한다. 적 수는 원본campaign.json의enemyCount에서 생성한다.
- 예고 카드에 적 번호와 원래 공격 표적을 표시한다. 다른 동료의 공격 스킬을 그 예고에 연결하면 대신 맞불을 걸고 선·표시가 바뀐다. 단일 공격 맞불을 지면 대신 나선 동료가 맞으며 광역 패배는 전원 피해다.
- 보스 예고는 4인 편성에서 4→5→6개, 3인 편성에서 3→4→5개로 증가한다. 최초 로스터의 열린 행동 수를 기준으로 하며 사망으로 감소하지 않는다. 부위 파괴로 해당 묶음은 함께 차단된다. 기존 보스 HP·위력·보상과 아군 행동 상한은 유지한다.
- 적 예고를 가로 불 타일로 표시한다. 원래 표적과 현재 맞불 담당을 남기고, 호버·키보드 포커스 시 위력·정신력·점등 확률·속도·부위·특수 효과·맞불 예측을 설명한다. 툴팁은 선택이나 배정을 바꾸거나 입력을 차단하지 않는다.
- 혼합 스테이지는 전투 전 대화, 승리, 후속 대화까지 완료해야 다음 구간이 열린다. 승리 후 종료했다면 후속 대화부터 이어진다.
- 메인 한 장이 캐릭터 한 명의 이야기다. 1장 리안·2장 세라·3장 노아·4장 하이델·5장 미나토로 명시하며 별도 개인편 메뉴와 런타임 카탈로그를 사용하지 않는다. 캐릭터 화면은 해당 메인 장으로 안내한다.
- 장마다 중심 인물의 과거에 합류·식사·원정 준비·의견 충돌·다른 동료의 대화를 엮는다. 인간과 군체 보스가 함께 등장한다.
- Unity와 브라우저가 같은 순수 C# Core로 전투·진행·저장을 계산한다.
- 정신력0 시작, -20~+20, 불 점화 확률50%+2%×정신력. 적도 같은 규칙의 어둠을 판정한다.
- 스킬은 기본 위력+켜진 불×불 위력. 매 맞불 비교에서 다시 점화하고, 2연승 후 마지막 위력으로 한 번 공격한다. 비교와 동률에는 피해가 없다.
- 속도는 행동 순서를 정한다. 동률은 연승을 초기화한다. 64회 비교의 교착은 피해 없이 종료한다.
- 7명의 1·2·3스킬과 방어 행동, 캐릭터별 동기화 저장. 등불 조각 10개와 해당 전용 재료(★5 10개 / ★4 6개)로 동기화 1을 열면 3스킬이 개방된다. 기존에 완료한 동기화는 보존한다. 레벨은 별도 값이며 현재 1이다. 미보유 캐릭터의 편성·동기화는 차단한다.
- 캐릭터별 덱은 1스킬 3장·2스킬 2장·동기화 후 3스킬 1장이다. 매 턴 미사용 카드까지 모두 버리고 새 ID의 후보 2장을 추첨한다. 남은 덱을 쓰고 부족하면 버린 카드를 섞는다. 같은 스킬이 다시 나올 수 있다. 방어 행동은 별도다.
- 행동은 전원 1개로 시작해 매 턴 파티 순서대로 한 명씩 두 번째 행동을 연다. 일반 R1~R5는 1111→2111→2211→2221→2222, 보스는 R3 이후 2211 상한이다. 전투 불능으로 순번을 당기지 않고 재시작은 R1로 돌린다.
- 모든 캐릭터의 1·2·3스킬과 방어 행동은 각 1행동이다. 3스킬의 불씨·위력·동기화는 유지한다. 후보 카드 2장을 제시하며 현재 행동 수만큼 사용한다. 잠긴 두 번째 행동은 UI·서버·추천·재사용에서 모두 차단한다.
- 후보 장수와 남은 행동 수를 구분하고, ‘2번 칸 배정’으로 슬롯 번호를 명시한다. 매 턴 두 장 전량 교체를 안내한다.
- 작전실에는 완료한 구간과 진행 가능한 다음 스테이지만 표시한다. 기록실은 완료한 이야기만 표시한다.
- 불 결과를 하나씩 공개하고 접전 점화는 라운드당2번까지 늘린다. 스킬별 준비·궤적·되돌아 베기·반동을 구분한다. 피해는 접촉 순간 한 번 적용한다.
- 턴별행동수와불씨6·등불·상성·어둠도·부위파괴·균열·속성반응을사용한다. 잠긴스킬은입력과추천에서제외한다.
- 방어·회피·반격은 일반 예고선을 보호한다. 관통·광역과 패배한 맞불에는 개입하지 않는다. 방어 경감은 최대85%, 회피와 반격은 행동당1회다.
- 보상 중복 방지, 등대3단계 복구, XML 저장·백업 복구, 기존 저장 파일 호환.
- 공유 전투 WAV 8종×3변형을 사용한다. 금속 맞불·베기·둔기·강타·바람·장비·불씨·파괴를 분리하며 접촉음은 실제 타격 순간 한 번 재생한다. 음소거·취소는 남은 소리를 멈추고 최대8개 소리의 합산 볼륨을 제한한다.
- 리안·세라·미나토·노아·하이델·카이·마레는 전투전용SD6포즈를 사용한다. 원화는 메인·대화·초상에 유지한다. 분노는 기존6포즈, 인간적은 자기 일러스트의 이동·기울임·반동으로 전투한다.
- 실행 중 스킬 바는 내려가고 맞붙는 두 인물과 효과를 확대한다. 접촉 정지·반동·피해 시점을 유지하며 다음 계획 턴과 취소 시 바와 배율을 복원한다. 움직임 간소화는 확대와 전환을 생략한다. 이동 배우의 이름과 현재 HP를 함께 표시하며, 고정 아군 이름표는 흐리게 한다. 점화판은 HP 바를 피하고 각 진영의 위력을 자기 불 옆에 표시한다.
- 귀항호 항해도는 완료한 구간과 다음 기항지만 연결하고 선택한 스테이지로 진입한다. 등대는 귀환 거점, 배는 연안 이동 거점이다. 내륙 임무는 정박 후 상륙 동선이다. 2-1 대화 4행과 새 배·바다 원화를 추가했다. 완료 구간은 다시 읽기·재출격에 맞는 안내를 표시한다.

- 현재 줄의 미공개 텍스트를 기록에서 숨기고 전체 대화는 스크롤로 읽는다. 기록·포커스 이탈은 타이핑과 자동을 멈추며, 선택한 1~6초 자동 대기는 완문 뒤에만 적용한다. 장면 내 좌우 유지·청자 대비와 실제 다음 행동 안내를 사용한다.
- 마레는 신규 ★4 화염 인양꾼이며 원화·전투 SD 6포즈와 독립 스킬을 갖는다. 기존 모집 저장 v1→v2는 마레만 1회 추가하며 기존 카이 소유·편성·성장·진행·재화·천장·난수·쿠폰을 보존한다. 신규 모집의 ★4 풀은 미나토·하이델·마레다.

## 초기 밸런스

위력·확률·정신력 증감·HP·동기화 비용은 변경 가능한 초기 수치다. 맞불 승리 정신력+2, 패배-2, 동료 전투불능 시 다른 생존 아군-3이다. 상성1.2/0.85, 수동 타이밍1.25/1/0.75와 기존 점화 연쇄 보정을 적용한다. 동일 시드·같은 입력은 같은 전투 이벤트를 재현하며 미리보기는 난수를 소비하지 않는다.

일반 첫 승리는 코인40·등불 조각2, 보스 첫 승리는 코인120·등불 조각10·기억1이다. 스토리 전용과 다시 읽기는 전투 보상을 지급하지 않는다. 기존 분노전의 저장 식별자는 유지해 중복 첫 보상을 막는다.

## 후속 제작
