## 1. 기획 의도

### 1.1 한 줄 컨셉
> **"태양이 꺼진 세계에서, 마지막 등불을 든 지휘관과 별의 조각을 품은 소녀들이 새벽을 되찾는 이야기."**

### 1.2 기획 방향
1. **2D 특화 전략**: Unity에서 3D 서브컬처 수준의 품질을 내려면 리소스 비용과 최적화 부담이 크다. 따라서 **Spine 2D 스켈레톤 애니메이션 + 고퀄리티 일러스트 + 셰이더 연출**로 승부한다.
2. **스토리가 과금 이유가 되는 게임**: 캐릭터 수집의 동기를 '스펙'보다 **'이 아이의 이야기를 끝까지 보고 싶다'** 에 둔다.
3. **어둠에서 시작해 빛으로 가는 구조**: 초반은 무겁고 고요하게, 진행할수록 색감·음악·UI가 점점 따뜻해지는 **"빛의 회복" 연출**을 게임 전반의 시스템으로 녹인다.
4. **가벼운 일상과 무거운 서사의 대비**: 거점 파트는 따뜻한 일상물, 전투·메인 스토리는 암울한 서사로 대비시켜 감정 진폭을 만든다.
5. **전투 시스템 자체가 차별점**: 평타 반복형 전투를 지양하고 '읽고, 잇고, 맞받아치는' 연결형 전투로 승부한다. 화려한 그래픽 대신 **시스템의 재미와 2D 연출(선·빛·타이밍)** 에 자원을 집중한다.

### 1.3 Unity 2D 한계 극복 방침
| 한계 | 대응 방안 |
|---|---|
| 3D 수준의 화려한 연출 부족 | 스킬 컷인 일러스트, 화면 분할, 카메라 셰이크, 파티클 + 2D 라이트로 대체. **연결 전투의 시스템적 손맛(빛실·맞불·점화)으로 그래픽 격차를 상쇄** |
| 캐릭터 표현력 | Spine 2D(메인) + Live2D(거점/로비 한정)로 역할 분리 |
| 대용량 일러스트 메모리 | Addressables + 텍스처 아틀라스 + ASTC 압축, 챕터 단위 로딩 |
| 저사양 기기 대응 | 그래픽 옵션 3단계, 라이트/포스트프로세싱 단계별 OFF |

## 2. 핵심 재미 요소 (Core Fun)

1. **수집·육성**: 개성 강한 "잔영(Afterglow)" 캐릭터 수집 및 관계 성장
2. **스토리 몰입**: 챕터마다 반전과 감정선을 가진 서사, 풀 보이스(핵심 씬)
3. **연결 전투**: 적의 예고선을 읽고 빛실을 이어 맞불을 놓는 전술 + 점화 타이밍의 손맛 (오토도 강력, 수동은 더 짜릿)
4. **빛의 회복 성장감**: 거점 "등대 요새"가 발전할수록 세계 색감이 바뀜

## 4. 게임 시스템 상세

### 4.1 게임 루프

```
[등대 요새 거점]  →  [스토리/탐사 출격]  →  [전투]
      ↑                                        ↓
[캐릭터 성장/건설] ←  [보상: 재화·파편·기억 조각]
```

- **단기 루프 (5~10분)**: 스태미나 소모 → 전투(3~5라운드) → 보상 획득
- **전투 루프 (라운드당 20~40초)**: 관측 → 연결 → 실행 → 정리 → (반복) — 상세는 4.2 참조
- **중기 루프 (1일)**: 일일 임무, 거점 관리, 캐릭터 육성
- **장기 루프 (주/월)**: 메인 챕터, 이벤트 스토리, 시즌 콘텐츠, 신규 캐릭터

### 4.2 전투 시스템 : 「연광(連光) 전투」 *(v0.2 전면 개정)*

#### 4.2.1 개편 배경과 설계 목표

기존안(ATB 순서대로 평타 → 게이지가 차면 스킬 버튼)은 유저의 결정이 사실상 **"스킬을 언제 누르느냐" 하나뿐**이라 기본 전투가 단조로워지고, 그래픽 경쟁에서 밀렸을 때 버틸 힘이 약하다. 이를 **"읽고 → 잇고 → 맞받아치는"** 연결형 전투로 전면 교체한다.

> **한 줄 컨셉**: 적의 행동이 미리 보이고, 유저는 **빛실(Light Thread)** 을 이어 "누가 · 무엇으로 · 누구를 상대할지" 결정한다.
> 주인공 '등불지기'가 잔영들의 빛을 이어 조율한다는 스토리 설정을 **그대로 조작으로 옮긴 시스템**이다.

| # | 설계 목표 | 해결 방향 |
|---|---|---|
| 1 | 매 라운드 **의미 있는 결정**이 있을 것 | 적의 행동을 예고선으로 공개 → 유저가 대응(맞불/공격/호위)을 선택 |
| 2 | **오토가 강력**할 것 | 상황 판단형 스마트 오토 + 전술 프리셋. 일반 콘텐츠는 풀 오토로 클리어 가능 |
| 3 | **수동 조작의 손맛** | 드래그 연결 + 맞불 충돌 + 점화 타이밍 + 균열 연출 |
| 4 | **2D 리소스로 구현 가능** | 3D 모델·물리 없이 선·빛·타이밍·카메라 연출과 시스템 깊이로 승부 |

**v0.1 대비 변경 요약**

| 항목 | v0.1 (기존) | v0.2 (개편) |
|---|---|---|
| 기본 행동 | 속도순 자동 평타 | 라운드마다 슬롯을 대상에 연결 |
| 유저 개입 | 게이지 찬 스킬 버튼 누르기 | 대상 지정 · 맞불 · 부위 선택 + 점화 타이밍 |
| 적 행동 | 별도 정보 없음 (턴 순서만 표시) | **예고선**으로 사전 공개 |
| 오토 | 평타 반복 | 상황 판단형 스마트 오토 + 전술 프리셋 |
| 배치 | 전열 / 후열 | 삭제 → **부위 지정**으로 대체 |
| 전투 자원 | 등불 게이지 | 불씨 · 등불 게이지 · 균열 · 어둠도 |
| 제작 부담 | 스킬 연출 중심 | 선·빛·타이밍 연출 중심 (캐릭터 애니 추가 부담 낮음) |

#### 4.2.2 전투 개요

| 항목 | 내용 |
|---|---|
| 파티 | 최대 4인 + 서포트 1인 (초반 챕터는 1~3인으로 시작해 스토리 진행에 따라 확장) |
| 진행 단위 | 라운드제 : ① 관측 → ② 연결 → ③ 실행 → ④ 정리 |
| 행동 슬롯 | 캐릭터당 **2슬롯** / 라운드 (서포트는 1슬롯, 지원·호위 연결만 가능) |
| 핵심 조작 | 슬롯에서 대상으로 **드래그(빛실 연결)**, 실행 중 **점화 타이밍 탭** (스킬당 1회) |
| 플레이 모드 | 수동 / 반자동 / 오토 (라운드 사이 언제든 전환) |
| 1라운드 소요 | 수동 약 25~40초 / 오토(1x) 약 15~20초 |
| 스테이지 길이 | 일반 3~5라운드, 보스 8~12라운드 |
| 랜덤 요소 | 최소화 (크리티컬·회피 확률 없음) → 결과는 **선택과 타이밍**이 결정 |

```
① 관측  →  ② 연결  →  ③ 실행  →  ④ 정리
(예고선)   (빛실 긋기)  (맞불·점화)   (정산)
```

용어 정의: **타점(Hit)** = 스킬 1회에 들어 있는 개별 타격 단위, **파워** = 타점 1개의 위력 수치. 예) "3타점 × 파워 9"

#### 4.2.3 라운드 상세

**① 관측 (Observe)** — 자동, 약 2초
- 적이 이번 라운드에 쓸 스킬과 대상이 **예고선(어둠의 실)** 으로 표시된다. (적 → 아군 방향의 보라·검정색 선)
- 예고선에는 스킬 아이콘 · **어둠 개수** · **최소~최대 위력** · 속도 · 속성이 표기된다.
- 적의 대상 선정은 **규칙 기반(랜덤 아님)** 이라 패턴을 익히면 예측할 수 있다.
- 보스는 부위(머리·팔·핵 등)별로 예고선이 나뉘어 표시된다.

**② 연결 (Link)** — 유저의 핵심 조작 단계 (PvE는 시간 제한 없음)

1. 각 슬롯에 사용할 스킬을 정한다. (기본기가 자동 배치되어 있으며, 탭하여 교체)
2. 슬롯에서 대상으로 **드래그**하여 빛실(따뜻한 앰버색 선)을 연결한다.

| 연결 대상 | 명칭 | 효과 |
|---|---|---|
| 적 본체 / 부위 | **공격 연결** (Strike) | 일방 공격. 속도 순서에 따라 명중하며, 부위를 지정하면 해당 부위의 균열 게이지에 추가 피해 |
| **적의 예고선** | **맞불 연결** (Clash) | 적의 공격을 **정면 상쇄**. 충돌 판정(4.2.4) 후 승자가 피해를 입힘 |
| 아군 | **호위 / 지원 연결** (Guard / Support) | 호위: 해당 아군을 향한 예고선을 대신 받아냄 / 지원: 치유·버프 |

3. 보조 조작
   - **일괄 연결**: 캐릭터 카드를 대상에 드래그하면 슬롯 2개가 같은 대상에 연결된다. 슬롯 단위 세부 조정도 가능.
   - **AI 제안**: 버튼 한 번으로 스마트 오토의 추천 연결을 미리 그려준다 → 수정 후 확정 (반자동의 기본 동작)
   - **이전 연결 재사용**: 직전 라운드의 연결을 그대로 복사
   - **스냅**: 대상 근처에서 손을 떼면 가장 가까운 유효 대상에 자동 흡착 (오조작 방지)
4. **예상 결과 미리보기 (필수 UX)**: 빛실 색으로 예상 승패를 표시한다.
   - 초록 = 맞불 우세 / 노랑 = 접전 / 빨강 = 열세, 선 위에 파워 비교 수치 표기
5. 이번 라운드 소비 불씨를 표시하고, 불씨가 모자라는 스킬은 비활성화한다.

**③ 실행 (Resolve)**
- 모든 연결(아군·적)이 **속도 수치가 높은 순서**로 하나씩 실행된다.
- 처리 방식: 맞불 → 4.2.4 판정 / 공격 연결 → 명중 / 호위·지원 → 효과 적용 / **맞불이 걸리지 않은 예고선은 그대로 목표 아군에게 명중**
- **행동 취소 규칙**: 자기 순서가 오기 전에 행동 주체가 **처치·균열 상태**가 되거나 예고선이 나온 **부위가 파괴**되면, 그 행동은 **취소**된다. → 속도가 빠른 아군이 적의 공격을 선제로 끊어내는 플레이가 가능
- 맞불 대상 예고선이 실행 전에 사라지면, 해당 슬롯은 그 적 본체에 대한 **공격 연결로 자동 전환**된다. (행동 낭비 방지)
- 실행 중 카메라는 진행 중인 연결에 줌인하고, 빛실이 팽팽해지며 충돌하는 연출이 재생된다.

**④ 정리 (Wrap-up)**
- 불씨 +3 회복(최대 6), 상태 이상·지속 효과 정산, 어둠도 변화 처리, 균열 상태 갱신, 다음 라운드 예고선 갱신

#### 4.2.4 정신력·불꽃·맞불(Clash)

- 아군과 적 모두 정신력 0에서 시작하고 -20~+20으로 제한한다.
- 각 스킬은 하나 이상의 불을 가진다. 아군은 금빛 불, 적은 보랏빛 어둠을 켠다.
- 점화 확률 = 50% + 정신력 × 2%. 범위는 10~90%다.
- 스킬 위력 = 기본 위력 + 점화된 불 개수 × 불 위력. 기존 수동 타이밍·상성·어둠도 배율을 적용한다.
- 맞불마다 양쪽 불을 다시 판정해 전체 위력을 비교하고 무기 충돌을 재생한다. 비교 자체에는 피해가 없다.
- 한쪽이 2번 연속 이기면 마지막 비교의 위력으로 공격한다. 승자가 바뀌면 새 승자의 연승은 1이다. 동률은 양쪽 연승을 0으로 만든다.
- 속도는 행동 순서를 정하며 위력 동률을 해결하지 않는다.
- 맞불 승자는 정신력 +2, 패자는 -2. 동료 전투불능 시 생존한 다른 아군은 -3이다.
- 64회 비교에도 승자가 없으면 피해 없는 교착으로 해당 행동을 마친다.
- 맞불 승리 자원은 등불 게이지 +10, 불씨 +1(라운드 최대 +2)이다.
- 최종 위력을 스킬 전체 피해로 한 번 환산한다. 불 개수만큼 전체 피해를 반복 적용하지 않는다.

| 비교 순서 | 결과 |
|---|---|
| 아군 승 → 아군 승 | 두 번 충돌한 뒤 아군 공격 |
| 적 승 → 적 승 | 두 번 충돌한 뒤 적 공격 |
| 아군 승 → 적 승 → 아군 승 → 아군 승 | 네 번 충돌한 뒤 아군 공격 |
| 아군 승 → 동률 → 아군 승 | 아직 1연승. 다음 비교를 계속 |

연결 단계의 우세·접전·열세 표시는 현재 정신력의 기대 위력과 기존 상성을 사용한다. 예측은 확률 계산이며 실제 점화 결과를 미리 추첨하지 않는다.

#### 4.2.5 점화 타이밍 (Ignite) — 수동 손맛의 핵심

- 스킬 실행 연출 중 **핵심 순간**에 타점 위로 **링이 수축**하고, 링이 겹치는 순간 화면을 탭한다. (스킬당 1회, 라운드당 최대 8~9회)

| 판정 | 타이밍 (가안) | 배율 | 연출 |
|---|---|---|---|
| **점화** (Perfect) | ±80ms | ×1.25 | 히트스톱 0.08초, 빛 폭발, 화면 진동, 높은 타격음, 강한 햅틱 |
| **양호** (Good) | ±200ms | ×1.0 | 기본 타격 연출 |
| **빗나감** (Miss) | 그 외 | ×0.75 | 빛실이 흔들림, 약한 타격음 |

- **연쇄 점화**: 점화를 연속 성공하면 배율이 +5%씩 누적(최대 +25%), 빗나감 시 초기화. 연쇄 수에 맞춰 타격음이 **음계처럼 한 음씩 상승**하고, 5연쇄 시 BGM에 레이어가 하나 얹힌다.
- 오토는 항상 **양호** 처리 → 수동 숙련 시 오토 대비 최대 약 +50% 효율. **오토를 벌하지 않으면서 수동에 보상**하는 구조.
- 접근성 옵션: 판정 창 확대(×1.5), 타이밍 자동 보조(항상 양호), 입력 지연 캘리브레이션

#### 4.2.6 전투 자원과 상태

| 자원 | 범위 | 획득 | 사용처 |
|---|---|---|---|
| **불씨(Ember)** | 0~6 (팀 공유) | 라운드 시작 +3 / 맞불 승리 +1 (라운드당 최대 +2) | 스킬 코스트 (기본기 0 / 전술 1~2 / 강화 3) |
| **등불 게이지** | 0~100 (팀 공유) | 맞불 승리 +10 / 점화 +3 / 적 균열 +15 / 피격 +2 | **등불 스킬** (100 소모) |

**등불 스킬 (궁극기 · 등불 해방)**
- 등불 게이지 100 → 연결 단계에서 캐릭터 1명을 선택해 사용, **슬롯을 소모하지 않는다.**
- 실행 단계 **맨 처음**에 발동: 풀스크린 컷인 연출 → **어둠도 -1**, 이번 라운드 아군 전체 점화 판정 창 +20% → 이후 일반 실행 진행
- 컷인 스킵 옵션 제공

**균열 (Rift) — 적의 방어층**
- 적마다 **균열 게이지**를 가진다. 공격 연결, 부위 지정, '파쇄' 반응으로 깎인다.
- 게이지가 0이 되면 **균열 상태**: ① 이번 라운드 남은 행동(예고선) 즉시 소멸 ② 다음 라운드 행동 불가 1회 ③ 1라운드간 받는 피해 +30%
- 적의 공격이 눈앞에서 끊기고 유리처럼 깨지는 순간이 **핵심 쾌감 포인트**

**어둠도 (Gloom) — 전장의 상태 (0~3단계)**

| 단계 | 점화 판정 창 | 추가 효과 | 화면 연출 |
|---|---|---|---|
| 0 | 100% | - | 기본 밝기 |
| 1 | 90% | - | 약간 어두워짐 |
| 2 | 80% | 그림자 속성 적 파워 +10% | 채도 감소 |
| 3 | 70% | 그림자 속성 적 파워 +20%, 불씨 회복 -1 | 최대 암전 + 비네트 |

- 상승 요인: 적의 특정 스킬, 아군 전투불능, 우울 개체
- 감소 요인: 광휘 속성 스킬, 등불 스킬, '정화' 반응
- 어둠도에 따라 2D 글로벌 라이트 강도와 UI 채도가 실시간으로 변한다 → 스토리의 '빛의 회복' 테마와 같은 문법의 연출을 **추가 리소스 없이** 구현

#### 4.2.7 속성 상성과 공명 반응

**속성 상성 (기존 유지)**

| 속성 | 상징 | 강함 | 약함 |
|---|---|---|---|
| 화염(炎) | 온기 | 서리 | 물결 |
| 서리(霜) | 정적 | 물결 | 화염 |
| 물결(潮) | 흐름 | 화염 | 서리 |
| 광휘(輝) | 희망 | 그림자 | - (광휘/그림자 상호 약점) |
| 그림자(影) | 심연 | 광휘 | - |

> 삼각 상성(화염·서리·물결) + 대극 상성(광휘·그림자)의 2단 구조. 상성 배율은 유리 ×1.2 / 불리 ×0.85 (가안)

**공명 반응 (신규)** — 같은 라운드에 **같은 대상에게 서로 다른 속성의 빛실 2개 이상이 명중**하면, 두 번째 명중 시점에 발동한다. 반응 효과는 **이후 실행되는 행동부터** 적용된다.

| 조합 | 반응 | 효과 |
|---|---|---|
| 화염 + 서리 | **파쇄** (Shatter) | 균열 게이지 피해 +50% |
| 화염 + 물결 | **증기** (Steam) | 대상 예고선 1개의 타점 -1 |
| 서리 + 물결 | **결빙** (Freeze) | 대상 속도 -30% (다음 라운드까지) |
| 광휘 + 아무 속성 | **정화** (Purify) | 어둠도 -1, 아군 상태 이상 1개 해제 |
| 그림자 + 아무 속성 | **잠식** (Siphon) | 가한 피해의 10%를 불씨로 환산 (라운드당 최대 +1) |

> 파티의 속성 조합이 곧 콤보 설계가 되므로, 수집·편성의 재미와 전투가 직접 연결된다.

#### 4.2.8 적 · 보스 설계

| 적 유형 | 예고선 수 | 특징 |
|---|---|---|
| 일반 | 1개 | 단일 부위, 균열 게이지 낮음 |
| 정예 | 2~3개 | 부위 1~2개, 특수 예고선 사용 |
| 보스 | 3~5개 | 다중 부위 + 페이즈 2~3단계 |

**부위 지정 (Weak Point)** — 전열/후열을 대체하는 2D 친화적 전략 요소
- 부위 예) **팔** = 파괴 시 해당 팔에서 나오는 예고선 영구 삭제 / **핵** = 균열 게이지 대형 피해, 파괴 시 페이즈 전환 / **머리** = 파괴 시 특정 스킬 봉인
- "맞불로 막을 것인가, 부위를 부숴 근원을 끊을 것인가"라는 공방의 선택지가 생긴다.

**특수 예고선**

| 종류 | 설명 | 대응 |
|---|---|---|
| 광역선 | 아군 전원에게 명중. **맞불에서 이기면 전원 보호**, 지면 전원 피해 | 파워가 높은 캐릭터로 맞불 / 부위·균열로 소멸 |
| 관통선 | 호위 연결을 무시 | 맞불로만 방어 |
| 허상선 | 가짜 예고선 (실제 피해 없음) | 깜빡임·색 번짐으로 식별, 맞불하면 낭비 |
| 연쇄선 | 명중 시 다음 예고선의 파워 강화 | 우선순위 처리 |

**보스 컨셉 : 애도의 5단계** — 스토리의 그림자 군체 설정과 전투 메커닉을 일치시킨다.

| 단계 | 등장 (가안) | 고유 메커닉 | 유저에게 요구되는 판단 |
|---|---|---|---|
| 부정 (Denial) | 프롤로그 | **허상선** 다수 혼재 | 진짜 예고선 구별, 낭비 없는 맞불 |
| 분노 (Anger) | 1장 | **광역선** 다수, 라운드가 지날수록 파워 상승 | 맞불 우선순위, 부위 파괴로 선 자체 삭제 |
| 타협 (Bargaining) | 2장 | 라운드 시작 시 **거래 제안**: 슬롯 1개를 포기하면 강한 예고선 1개 취소 + 불씨 +2 | 손해와 이득의 저울질 (수락/거절) |
| 우울 (Depression) | 3장 | 라운드마다 **어둠도 자동 상승**, 불씨 회복 저하 | 빠른 처치, 광휘 속성/등불 스킬 타이밍 |
| 수용 (Acceptance) | 5장 | 맞불에서 패배한 타점을 **흡수해 자기 타점으로 전환** | 맞불 리스크 관리 → 부위 파괴·균열로 돌파 (정체 공개와 연동) |

> 4장은 스토리상 '진실' 챕터로, 관측소를 배경으로 한 특수 규칙 스테이지로 별도 기획한다.

**인간 보스 확장 (2026-10-12)** — 봉쇄국, 회색 인장 연합, 철종 교단의 안식 집행부가 의도적으로 통행·배급·기록을 통제한다. 인간 지휘관에게는 무기·인장 장비·손종·기록 봉인과 병사들의 호위선을 사용한다. 구금·항복·피난로 확보를 스테이지 목표로 두고, 제압 뒤에도 명령과 기록에 대한 책임이 남도록 한다.

리안의 옛 경계 동료 로웬은 인간 중간 보스, 세라의 고아원 친구 엘렌과 노아의 교단 친구 이브는 인간 엔딩 보스로 구성한다. 군체와 인간의 갈등이 이어지는 상세 흐름은 [인간 적대 세력과 관계 서사](05_인간_적대세력과_관계서사.md)를 따른다. 현재 메인 캠페인에 인간 보스전과 전용 초상화를 연결했다. 고유 다중 페이즈와 보스 음악 음원 연결은 후속 구현이다.

#### 4.2.9 스마트 오토 (수동 / 반자동 / 오토)

| 모드 | 빛실 연결 | 점화 타이밍 | 용도 |
|---|---|---|---|
| 수동 | 유저 | 유저 | 손맛, 고난도 도전 |
| 반자동 | AI 제안 → 유저가 확정/수정 | 유저 | 편하게 즐기되 핵심만 개입 |
| 오토 | AI | 양호 고정 | 파밍, 소탕, 복습 |

**스마트 오토 판단 순서 (Utility AI)**
1. 예고선 위협도 평가 (예상 피해 × 대상 가치)
2. 맞불 승산 계산 → 임계치 이상이면 맞불 연결
3. 열세라면 호위/지원 연결, 또는 부위 파괴로 예고선 삭제
4. 남은 슬롯은 균열 게이지 압박 → 처치 가능한 대상 마무리
5. 불씨·등불 게이지 사용 판단 (보스 페이즈 전환·균열 타이밍에 등불 스킬)

**전술 프리셋**
- 캐릭터별 성향(공격형 / 균형형 / 방어형) + 조건 규칙 최대 3개 (예: "아군 HP 40% 이하 → 치유사는 지원 연결 최우선")
- 프리셋 3개 저장, PvP 방어덱의 AI로도 재사용

**오토 설계 원칙**
- 메인 스토리와 일반 던전은 **풀 오토로 클리어 가능**하도록 밸런싱한다.
- 오토 중에도 빛실이 **한 줄씩 그려지는 연출**을 보여 관전하는 재미를 확보한다.
- AI가 왜 그렇게 판단했는지 **라운드 로그**로 확인할 수 있게 한다. (학습 효과 → 수동 유입)
- 도전 콘텐츠는 수동 개입이 유리한 요소(허상선 판별, 부위 지정, 연쇄 점화)를 별도로 설계한다.
- 배속 1x / 2x / 3x, 연출 스킵, 클리어 스테이지 소탕 지원

#### 4.2.10 손맛 연출 가이드 (2D로 구현하는 쾌감)

| 순간 | 연출 | 구현 방법 (Unity) |
|---|---|---|
| 빛실 드래그 | 손끝에서 빛이 실처럼 늘어남, 유리 종소리, 대상 근처에서 미세 진동 | 메시 기반 라인 + Shader Graph, 햅틱 |
| 연결 확정 | 선이 팽팽해지며 앰버색으로 점등 | DOTween, 스프라이트 이펙트 |
| 맞불 충돌 | 충돌 지점 스파크 + 0.3초 슬로우 + 화면 분할 컷 | 애니 속도 조절, 파티클 |
| 점화 | 히트스톱 + 화면 균열 셰이더 + 빛 폭발 | Cinemachine Impulse, 디스토션 셰이더 |
| 균열 | 유리 깨지는 효과 + 적 예고선 일제히 소멸 | 스프라이트 시퀀스, 파티클 |
| 등불 스킬 | 풀스크린 컷인 일러스트 + 타이포 연출 | Timeline |
| 어둠도 변화 | 조명 강도·UI 채도가 서서히 변화 | URP 2D Global Light |

> 손맛의 대부분이 **선 · 빛 · 타이밍 · 카메라**로 만들어지므로 캐릭터별 애니메이션 세트를 늘리지 않고도 쾌감을 확보한다. 2D 서브컬처의 제작비 구조와 잘 맞는 방식이다.

#### 4.2.11 전투 예시

세라는 팔을 공격해 예고선을 없애고, 리안은 광역 예고선에 맞불을 연결하며, 미나토는 부상한 아군을 회복한다. 리안과 적은 매 비교마다 불과 어둠을 켜 전체 위력을 겨룬다. 리안이 이기고 적이 이기면 두 번 모두 무기 충돌만 발생한다. 이후 리안이 두 번 연속 이겨야 리안이 실제 공격하고 광역 공격을 취소한다. 적이 두 번 연속 이기면 광역 공격이 실행된다. 부위 파괴와 균열은 실행 전 예고선을 없애는 다른 대응 수단이다.

### 4.3 캐릭터 시스템

**희귀도**: ★3 / ★4 / ★5 (★5는 스토리 핵심 인물)

**역할군 (연결 특화 포함)**

| 역할 | 설명 | 연결 특화 |
|---|---|---|
| 수호자(Guardian) | 탱커, 아군 보호 | **호위 연결** 강화, 다타점 방어 스킬로 맞불 유지력이 높음 |
| 돌격수(Striker) | 근접 딜러 | 고파워 피니시형 타점, 맞불 승리 시 추가 피해 |
| 사수(Marksman) | 원거리 딜러 | 연사형 다타점, **부위 지정 · 균열 게이지** 특화 |
| 술사(Caster) | 광역/속성 딜러 | 1스킬로 다중 대상 연결, **공명 반응** 유발 |
| 치유사(Healer) | 회복, 정화 | **지원 연결**, 어둠도 정화 |
| 조율사(Tuner) | 버프/디버프, 게이지 조작 | 이미 그은 빛실 **재연결(Relink)**, 불씨 생성, 점화 판정 창 확대 |

**스킬 구성 (캐릭터당)**

| 구분 | 코스트 | 불 | 슬롯 | 개방 |
|---|---|---|---|---|
| 1스킬 | 0 | 1개 이상 | 1칸 | 기본 |
| 2스킬 | 1~2 | 1개 이상 | 1칸 | 기본 |
| 3스킬 | 2~3 | 1개 이상 | 1~2칸 | 동기화 1 |
| 방어·회피·반격 중 하나 | 현재 0 | 1개 이상 | 1칸 | 기본 |
| 등불 스킬 | 등불 게이지 100 | 특수 | 0칸 | 게이지 조건 |

- 캐릭터별 위력·불 개수·특수 효과는 개별 데이터에서 설정한다. 미나토의 2·3스킬은 회복 기술이다.
- 잔영 기록에서 등불 조각 10개로 해당 캐릭터의 동기화 1을 개방한다. 레벨과 별도 저장하며 3스킬 잠금은 UI·추천·전투 입력에서 모두 검증한다.
- 방어 행동도 점화에 따라 위력이 증가한다. 리안·미나토는 방어, 세라·노아는 회피, 하이델은 반격을 사용한다.

**성장 요소**
- 레벨 / 동기화(레벨과 별도, 3스킬 개방) / 돌파(각성) / 스킬 레벨 / 장비 "기억의 유물"
- **유대(Bond) 시스템**: 캐릭터와의 호감도 상승 → 전용 서브 스토리, 보이스, 일러스트 해금
- **잔영 각성**: 별의 파편을 깨우는 최종 각성 → 일러스트 및 스킬 연출 변화

### 4.4 거점 시스템 : 「등대 요새」

- 폐허가 된 등대에서 시작 → 시설을 건설/복구할수록 요새가 밝아짐
- **2D 횡스크롤 거점 화면** (Live2D 캐릭터가 돌아다님)
- 시설 예시

| 시설 | 기능 |
|---|---|
| 중앙 등탑 | 요새 레벨, 세계 밝기 단계 결정 |
| 작전실 | 스테이지 선택, 파견 |
| 숙소 | 캐릭터 휴식, 유대 이벤트 |
| 식당 | 버프 요리, 일상 이벤트 |
| 공방 | 장비 제작/강화 |
| 기록실 | 스토리 다시보기, 도감 |

- **빛 단계 시스템**: 요새 레벨에 따라 UI 컬러, 로비 BGM, 배경 색조가 **회색 → 청회색 → 따뜻한 주황**으로 변화

### 4.5 콘텐츠 구성

| 콘텐츠 | 설명 | 오픈 시기 |
|---|---|---|
| 메인 스토리 | 챕터형 VN + 전투 | 런칭 |

| 길드 (등불단) | 협동 보스 레이드 (다중 부위를 멤버가 분담 공략) | 런칭 후 2개월 |
| PvP (거울 회랑) | 비동기 대전. 방어측은 전술 프리셋(AI)이 연결을 수행, 공격측은 수동/오토 선택 | 런칭 후 3개월 |

### 4.6 스토리 연출 시스템 (Visual Novel)

- 캐릭터 스탠딩 (Spine 표정/모션 교체) + 배경 + 이벤트 CG

## 5. 재화 및 수익 모델

### 5.1 재화 구조

아래 표는 장기 재화 계획이다. 현재 프로토타입은 별가루로 모집하고, 등불 조각은 동기화에 사용한다. 테스트 지급과 현재 보유·편성은 [모집 구현 규칙](08_픽업_모집_보유편성_테스트쿠폰.md)을 따른다.

| 재화 | 용도 | 획득 |
|---|---|---|
| 별가루 (유료) | 소환 | 결제, 일부 무료 지급 |
| 등불 조각 (무료) | 소환 / 일부 상점 | 임무, 스토리 |
| 코인 | 성장 기본 재화 | 전투, 파견 |
| 기억의 파편 | 캐릭터 돌파 | 던전, 상점 |
| 스태미나 (등유) | 스테이지 입장 | 시간 회복 |

### 5.2 과금 모델
- **소환(가챠)**: ★5 기본 확률 0.8%, **80회 이내 ★5 확정**. ★5 중 픽업 50%, 비픽업 당첨 뒤 다음 ★5는 픽업 확정이다. 배너 간 천장·확정 상태를 공유한다. 현재 기본 지급은 리안 ★5와 미나토·하이델·마레 ★4다. [모집·보유·편성·테스트 쿠폰 상세](08_픽업_모집_보유편성_테스트쿠폰.md)를 따른다.
- **월정액 패스 / 시즌 패스**
- **성장 패키지**
- **스킨 / 의상**: 스토리 외 외형 콘텐츠
- 원칙: **"스토리는 무료로 끝까지, 캐릭터는 취향으로 과금"** — 메인 스토리는 무과금으로 클리어 가능

### 5.3 유저 친화 정책
- 무료 소환 재화를 넉넉하게 지급 (메인 스토리 진행 보상)
- 확률/천장 정보 명확 공개
- 중복 캐릭터는 돌파 재화로 환원

## 6. 아트 디렉션

### 6.1 컬러 스크립트 (빛의 회복)
| 단계 | 분위기 | 팔레트 |
|---|---|---|
| 1장 (영야) | 절망, 정적 | 짙은 남색, 회색, 탁한 청록 |
| 2~3장 | 희미한 희망 | 청회색 + 포인트 앰버 |
| 4~5장 | 재건 | 따뜻한 주황, 크림 |
| 최종장 | 새벽 | 금빛, 연분홍, 하늘색 |

### 6.2 스타일 가이드
- **캐릭터**: 일본 서브컬처 스타일 + 얇은 라인, 셀 셰이딩 느낌의 페인팅
- **배경**: 폐허 도시, 안개, 얼어붙은 시계탑 등 **"고요한 디스토피아"**
- **UI**: 유리 조각/등불 유리 모티프, 다크 톤 베이스에 앰버 포인트 컬러
- **전투 라인 비주얼**: 아군 빛실 = 따뜻한 앰버, 적 예고선 = 탁한 보라·검정 → 색만으로 한눈에 구분. 색약 모드에서는 실선/점선 패턴을 추가
- **폰트**: 본문 가독성 우선 산세리프, 타이틀은 세리프 계열

### 6.3 제작 파이프라인
1. 컨셉 아트 → 2. 일러스트 (풀바디) → 3. 파츠 분리 → 4. Spine 리깅 → 5. Unity 임포트 → 6. 셰이더/이펙트 적용

### 8.2 최적화 원칙

- Spine 메시 트리 최소화, 슬롯 수 제한

- 전투 씬과 로비 씬 비동기 로딩 분리

### 8.3 아키텍처 메모
- 전투 로직과 연출 분리 (**결정론적 전투 계산 + 연출 큐**) → 리플레이, 오토, 배속에 유리
- 데이터 드리븐 설계 (스킬, 캐릭터, 스테이지 전부 테이블화)

### 8.4 연광 전투 구현 메모 (v0.2 추가)

| 모듈 | 역할 | 구현 메모 |
|---|---|---|
| `BattleSimulator` | 순수 C# 전투 로직 (MonoBehaviour 비의존) | 라운드 계획을 받아 이벤트 리스트 생성, 시드 고정으로 결정론 보장 |
| `LinkPlanner` / `AutoPlanner` | 유저 입력과 AI 제안을 같은 형식으로 통일 | 둘 다 `RoundPlan`(슬롯 → 대상 매핑)을 생성해 시뮬레이터에 전달 |
| `LinkResolver` | 속도순 정렬, 맞불 판정, 공명 반응 계산 | 결과를 `BattleEvent` 큐로 출력 |
| `PresentationQueue` | 이벤트 큐를 연출로 재생 | Timeline / DOTween, 배속·스킵 지원 |
| `LinkLineRenderer` | 빛실·예고선 렌더링 | 베지어 메시 + Shader Graph(흐름/맥동), 오브젝트 풀링 |
| `TimingInputSystem` | 점화 타이밍 입력 | New Input System, **입력 지연 캘리브레이션**, 오디오 DSP 시간 기반 판정 |
| `TacticsPreset` | 오토 규칙 데이터 | ScriptableObject/JSON, 서버 저장 (PvP 방어덱 재사용) |

- **결정론 & 검증**: 전투 결과 = (초기 상태 + 라운드별 `RoundPlan` + 점화 판정 결과)의 함수 → 서버 재계산으로 PvP·랭킹 검증과 리플레이가 가능
- **스킬 데이터 스키마(`SkillData`)**: 타점 수, 타점별 파워 배열, 속도, 코스트, 속성, 연결 가능 유형, 부위 피해, 효과 목록, 슬롯 점유(1 or 2)
- **밸런스 자동 검증**: `BattleSimulator`를 헤드리스로 돌려 **수만 판의 오토 시뮬레이션**으로 캐릭터·스테이지 밸런스를 검증
- **성능**: 빛실 라인 배칭(일괄) 렌더링, 이펙트 풀링, 전투 UI Canvas를 정적/동적으로 분리

## 10. 튜토리얼 및 FTUE (첫 30분)

1. 암전 → 사운드만으로 시작하는 오프닝 (30초)
2. 첫 전투: 예고선만 보이고 대응 수단이 없는 강제 패배 연출 → 등불 각성으로 **첫 빛실 연결** (연결 개념 체험)
3. 첫 캐릭터(★5 "리안") 합류 → **연결 튜토리얼** (① 공격 연결 ② 맞불 연결 ③ 점화 타이밍 ④ 균열) — 한 전투에 한 개념씩 3~4개 전투로 분산, 완료 후 반자동/오토 순차 해금
4. 요새 첫 등불 점등 → 거점 시스템 소개
5. 리안 ★5와 미나토·하이델·마레 ★4의 기본 4인 지급 → 소유 편성 확인과 선택 픽업 안내
6. 챕터 1 클리프행어로 마무리

> **목표**: 30분 내 감정 이입(캐릭터) + 시스템 이해 + 다음 스토리 궁금증 확보
