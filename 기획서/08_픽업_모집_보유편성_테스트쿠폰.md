# 픽업 모집·보유·편성·테스트 쿠폰

2026-10-15. 사용자 요청인 기본 ★5 한 명 + ★4 세 명, 80회 천장과 픽업 실패 후 다음 ★5 확정을 구현 기준으로 삼는다. 기본 확률·비용·중복 보상은 조정 가능한 초기 수치다.

## 기본 지급과 스토리

| 인물 | 희귀도 | 역할 |
|---|---|---|
| 리안 | ★5 | 광휘 · 수호자 |
| 미나토 | ★4 | 물결 · 치유사 |
| 하이델 | ★4 | 서리 · 사수 |
| 마레 | ★4 | 화염 · 인양꾼 |

기존 ★4 두 명에 신규 동료 마레를 추가한다. 카이는 이야기의 주인공으로 유지한다. 이전 테스트에서 카이를 보유·성장·편성했다면 계속 사용할 수 있지만 신규 기본 지급과 소환 풀에서는 제외한다. 마레는 갈고리와 구조줄의 물리 타격, 회피, 동기화로 여는 3스킬을 갖는다. 새 원화와 전투 전용 SD 6포즈를 사용한다.

세라·노아는 처음에 미보유이며 모집으로 얻는다. 등장인물의 본편 합류와 캐릭터 소유를 분리한다. 미보유 인물도 해당 장의 대화에는 등장하고 기록을 열람할 수 있다. 미보유 인물의 동기화와 편성은 차단한다.

실제 전투에는 저장된 **보유 캐릭터 4인 편성**을 사용한다. 소유한 캐릭터 상세에서 교체할 자리를 선택한다. 이미 편성한 인물을 다른 자리에 넣으면 두 자리를 서로 바꾼다. 스테이지 원본의 `party`는 장면 속 동행을 나타내는 서사 자료로 남긴다. 초반 튜토리얼 적의 기존 HP 보정은 유지한다.

## 배너와 확률

- 리안·세라·노아의 픽업 배너 세 개를 선택할 수 있다.
- 1회 **별가루 160개**, 10회 **1,600개**. 10회는 같은 규칙으로 한 회씩 순서대로 계산한다.
- 기본 ★5 확률 **0.8%**. ★5에 당첨되면 해당 픽업 50%, 다른 ★5 두 명은 각각 25%다. 천장과 다음 픽업 확정이 없는 한 회에서 픽업은 0.4%, 다른 ★5는 각각 0.2%다.
- ★5가 아니면 미나토·하이델·마레 ★4 세 명 중 균등하게 한 명을 얻는다. 현재 모집 풀에는 ★3가 없다. 호환 캐릭터 카이는 확률 표와 신규 모집 대상에서 제외한다.
- ★5 없이 79회를 진행하면 **다음 80회째는 반드시 ★5**다. 80회 이전에 ★5가 나와도 천장 횟수는 0으로 돌아간다.
- 비픽업 ★5가 나오면 **다음 ★5는 선택한 배너의 픽업 확정**이다. 다음 한 회가 무조건 ★5라는 뜻은 아니다.
- 픽업 확정은 픽업 ★5를 얻을 때 소모한다. 천장에서 비픽업이 나와도 같은 확정 규칙을 적용한다.
- **모든 캐릭터 픽업 배너가 천장과 확정 상태를 공유**한다. 배너 변경과 게임 재시작으로 초기화하지 않는다.
- 중복은 ★4 **캐릭터 조각 20개**, ★5 **100개**로 환원한다. 중복이 동기화나 레벨을 자동으로 올리지는 않는다. 조각의 추가 소비처는 후속 제작 범위다.

모집 화면에서 현재 재화, 천장 진행, 남은 횟수, 다음 ★5 픽업 확정 여부, 확률 상세를 확인한다. 결과에는 희귀도·이름·신규 또는 중복 조각을 표시한다.

## 테스트 쿠폰

등대 요새에서 **설정 → 테스트 쿠폰**으로 입력한다. 원정 중에는 사용할 수 없다.

| 코드 | 지급 |
|---|---|
| `LANTERN-TEST-9999999` | 별가루·코인 각각 **9,999,999개** |
| `LANTERN-MATERIALS` | 등불 조각·기억의 파편·캐릭터 조각 각각 **9,999,999개** |
| `LANTERN-SYNC-MATERIALS` | 캐릭터 전용 동기화 재료 7종 각각 **9,999,999개** |

각 코드는 **저장 파일당 한 번** 사용한다. 영문 대소문자와 공백 차이는 정규화한다. 잘못된 코드·중복 코드·보관 한도 초과는 아무것도 소비하거나 지급하지 않는다. 테스트 코드와 큰 지급량은 현재 개발 버전의 검수 기능이다.

## 저장과 이전 데이터

- 모집 재화, 보유 목록, 편성, 천장, 픽업 확정, 쿠폰 사용 기록과 모집 전용 난수 상태를 저장한다. 전투 난수와 모집 난수는 분리한다.
- 모집·쿠폰·편성 변경은 저장이 성공한 뒤 결과를 알린다. 저장 실패 시 재화·소유·편성·난수·천장·쿠폰 사용을 함께 복원한다. 저장 실패 후 재시도로 새로운 결과를 다시 고르지 않는다.
- 이전 저장은 클리어·성장·기존 재화를 보존하고 기본 4인의 명시적 소유·편성으로 이관한다. 예전에는 캐릭터 열람과 전투 표시만으로도 성장 항목이 생성됐으므로, 그 항목을 유료 획득이나 캐릭터 소유의 증거로 삼지 않는다. 미보유 ★5의 과거 성장 값은 획득 뒤 다시 사용한다.
- 이미 모집 기능을 사용한 v1 저장은 v2 이관에서 마레만 한 번 추가한다. 기존 카이 소유·편성·동기화, 다른 보유와 진행·재화·천장·픽업 보증·난수·쿠폰 기록은 유지한다. 편성을 강제로 마레로 바꾸지 않으며 다시 불러와도 추가 지급하지 않는다.
- 열람이나 전투 반영으로 새 캐릭터를 자동 지급하지 않는다.
