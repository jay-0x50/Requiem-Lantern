## 1. 스토리 한 줄 요약

> 태양이 사라진 지 **13년**. 모든 것을 잃은 세계에서, 기억을 잃은 채 깨어난 **'등불지기'**는 별의 파편을 품은 소녀들과 함께 마지막 빛을 지키기 위해 걸음을 떼는데…

---

## 2. 세계관

### 2.1 영야(永夜) — 태양이 꺼진 세계
- 13년 전 **"소등(消燈)의 날"** 하늘의 태양이 하루아침에 빛을 잃음
- 이후 세계는 **영구적인 어둠과 안개** 속에 잠겨 있음
- 기온 저하, 작물 소멸, 문명 붕괴로 인구의 90%가 사라짐
- 밤하늘에는 별도 없이 **검은 균열(Rift)**만 존재

### 2.2 그림자 군체 (Umbra)
- 빛과 온기를 먹고 자라는 존재
- 사람의 **그림자**에서 태어나기도 함 → 절망이 깊을수록 강해지고 변이
- 개체별 이름 대신 **'애도(哀悼)'의 단계 이름**으로 분류
  - 부정 / 분노 / 타협 / 우울 / 수용
- 최종 목표는 모든 빛의 소멸 (= 세계의 완전한 종결)

### 2.3 잔영 (Afterglow)
- 태양이 부서질 때 흩어진 **별의 파편**이 인간의 몸에 깃든 존재
- 대부분 소녀의 모습으로 발현 (원인 불명, 후반 반전 요소)
- 파편에는 **주인의 가장 강한 기억**이 각인됨
- 힘을 쓸수록 **기억을 조금씩 잃는 대가**가 있음 → 시스템의 '기억의 파편'과 연결

### 2.4 등불지기 (Lampbearer)
- 잔영들의 빛을 증폭시키고 조율할 수 있는 유일한 존재
- 고대에는 **'태양을 지키던 자'**로 불렸다는 전승
- 플레이어 = 기억을 잃은 등불지기

### 2.5 주요 지역

| 지역 | 설명 |
|---|---|
| **등대 요새 (Beacon Keep)** | 첫 거점. 폐허가 된 해안 등대. 마지막 불씨가 남아 있음 |
| **잿빛 시가지 (Ashen Ward)** | 얼어붙은 옛 수도. 거대한 시계탑이 정지해 있음 |
| **유리 정원 (Glass Garden)** | 빛을 잃은 식물원. 얼어 결정화된 꽃들 |
| **침묵의 해구 (Silent Trench)** | 그림자 군체가 밀집한 바다 |
| **여명의 탑 (Tower of Dawn)** | 태양이 꺼진 원점, 최종 지역 |

### 2.6 세력

| 세력 | 성향 | 설명 |
|---|---|---|
| **등불단 (Lantern Corps)** | 주인공 세력 | 생존자들의 저항 조직, 초기 인원 극소수 |
| **철종 교단 (Iron Bell Order)** | 대립/중립 | "빛은 이미 죽었다"며 어둠을 받아들이자 주장 |
| **관측소 (The Observatory)** | 비밀 | 소등의 날의 진실을 알고 있는 옛 연구 기관 |
| **봉쇄국** | 인간 적대 조직 | 피난문·통행권·배급 명부를 통제하는 해안 경비 조직. 명부 밖 생존자를 지우고 구조를 막음 |
| **회색 인장 연합** | 인간 적대 조직 | 약품·식량·운송로를 독점하는 연합. 배급표를 이용해 피난민을 통제하고 구조 통로를 무력으로 봉쇄 |

철종 교단의 **안식 집행부**는 강제 안식과 기록 말소를 집행하는 인간 적으로 등장한다. 각 세력 안에 일반 주민·신도도 있으며, 폭력과 배제의 명령을 내리는 인물과 조직을 중심으로 대립을 만든다. 상세는 [인간 적대 세력과 관계 서사](05_인간_적대세력과_관계서사.md)를 따른다.

## 3. 주요 등장인물

### 3.1 주인공 — 등불지기 (플레이어)
- 이름: 플레이어 입력 (기본 이름 **'카이(Kai)'**)
- 성별: 중립 (일러스트 노출 최소화, 목소리 없음)
- 상황: 얼어붙은 폐허 속에서 **혼자 깨어남**. 자기 이름 외의 모든 기억이 없음
- 특징: 손에 **꺼져가는 낡은 등불** 하나를 쥐고 있음
- 비밀: 소등의 날에 일어난 사건의 열쇠
- 전투 구현(2026-10-15): 기본 ★4 / 광휘 / 등불지기로 편성한다. 등불을 이용한 공격과 방어를 사용하며 본편의 조율자 역할을 유지한다. 실제 전투 편성은 소유 목록을 따르고, 서사 속 동행은 뽑기 여부와 관계없이 진행한다.

### 3.2 리안 (Lian) — ★5 / 광휘 / 수호자
- **첫 동료, 히로인 격 메인 캐릭터**
- 외형: 은백색 단발, 한쪽 눈이 파편으로 빛나는 금색
- 성격: 무뚝뚝하고 냉정하지만 속은 여림. 웃는 법을 잊음
- 사연: 소등의 날에 가족을 잃고 13년간 홀로 요새를 지킨 파수꾼
- 대사 톤: 짧고 건조함 — "…살아 있으면, 그걸로 됐어."
- 파편 대가: 어린 시절의 기억 대부분을 이미 상실

### 3.3 세라 (Sera) — ★5 / 화염 / 돌격수
- 외형: 붉은 장발 포니테일, 그을린 코트
- 성격: 밝고 시끄러운 낙천가. 그러나 웃음은 **가면**
- 사연: 사라진 고아원 아이들을 찾아 헤매다 요새에 합류
- 대사 톤: "괜찮아 괜찮아! 어둠 따위, 내가 태워버릴 테니까!"
- 반전: 그녀가 찾는 아이들은 이미 그림자 군체가 되었음

### 3.4 미나토 (Minato) — ★4 / 물결 / 치유사
- 외형: 청록색 머리, 낡은 의무복, 언제나 졸린 눈
- 성격: 나른하고 다정한 의사 지망생
- 사연: 치료를 못 해 잃은 환자들의 이름을 전부 외우고 있음

### 3.5 노아 (Noa) — ★5 / 그림자 / 조율사
- 외형: 검은 후드, 보라빛 눈, 창백한 피부
- 성격: 냉소적이고 수수께끼 같은 소녀. **그림자 속성 잔영**이라는 이단
- 사연: 철종 교단 출신의 탈주자. 그림자와 대화가 가능
- 역할: 중반 이후 주요 열쇠 캐릭터

### 3.6 하이델 (Heidel) — ★4 / 서리 / 사수
- 외형: 갈색 단발, 고글, 개조 석궁
- 성격: 실용주의 기술자. 요새의 공방 담당
- 사연: 관측소 붕괴 후 유일하게 살아남은 연구원 (복선)

### 3.7 안타고니스트

| 인물 | 설명 |
|---|---|
| **종지기 오르페 (Orphe)** | 철종 교단의 수장. 온화한 미소로 "안식"을 설파. 누구보다 빛을 사랑했던 자 |
| **'수용(受容)' — 최후의 그림자** | 소등의 날에 태어난 최초의 군체. 진정한 정체는 후반부 공개 |
| **로웬 — 봉쇄국 경비대장** | 리안과 야간 경계를 나누던 동료. 지금은 명부 밖 피난민의 구조를 막는 인간 중간 보스 |
| **엘렌 — 봉쇄선의 집행관** | 세라와 고아원 아이들을 돌보던 친구. 현재 회색 인장 연합의 독점 배급과 통로 봉쇄를 집행하는 인간 엔딩 보스 |
| **이브 — 침묵의 기록관** | 노아를 처벌에서 지켜 주던 가까운 친구. 현재 강제 안식과 인명 기록 말소를 명령하는 교단의 인간 엔딩 보스 |

새 인간 인물들은 적대 행위를 자신의 의지로 선택하며, 패배 후에도 인간으로 남는다. 좋은 과거와 현재의 가해를 함께 보여 줘, 친밀함이 책임을 지우지 않도록 한다.

## 4. 핵심 미스터리와 진실 (스포일러 주의)

> ⚠️ 개발팀 내부용 — 라이브 서비스 중 단계적으로 공개

1. **태양은 파괴된 것이 아니라, 스스로 꺼졌다.**
   13년 전 관측소는 태양의 붕괴를 예측했고, 그것을 막기 위해 **'인간의 기억을 연료로 태양을 다시 점화하는 실험'**을 시도했다.
2. **잔영 소녀들은 그 실험의 희생자/피험자다.** 별의 파편은 사실 '태양의 조각'이 아니라 **실험체들의 기억이 결정화된 것**이다.
3. **주인공(등불지기)은 실험 총책임자의 후손, 혹은 그 자신이다.** 기억을 잃은 것은 스스로 봉인했기 때문.
4. **그림자 군체는 잃어버린 기억과 감정의 잔해**다. 즉 "죽은 이들의 못다 한 마음"이다.
5. **결말의 선택**: 태양을 다시 켜는 데는 여전히 '기억'이 필요하다. 누구의 기억을 바칠 것인가.

## 5. 메인 스토리 구성

### 프롤로그 : 「마지막 불씨」
- 암전. 바람 소리와 얼음이 갈라지는 소리
- 주인공이 눈을 뜬 곳은 무너진 시가지 지하. 손에는 희미하게 깜빡이는 등불
- 그림자 군체 **'부정'** 개체 습격 → 강제 패배 연출
- 죽음 직전, 은백색 머리의 소녀 **리안**이 등장해 구출
- 등불이 리안의 파편과 공명 → **첫 등불 해방** 발동, 최초의 승리
- 리안: "…네 그 불, 아직 꺼지지 않았네." (그녀의 첫 표정 변화)

### 제1장 : 리안 · 「돌아올 사람을 위한 불」

- 무대는 꺼진 등대와 영야의 폐허. 카이의 각성과 첫 공명은 이 장의 시작 스테이지다.
- 리안이 13년간 요새를 지킨 이유와 잃어버린 가족의 기억을 구조 신호·문·야간 경계 장면에 연결한다.
- 세라·미나토의 합류와 첫 식사에서 리안의 태도가 조금씩 달라진다.
- 옛 동료 로웬이 생존자를 봉쇄한다. 리안은 기다리던 사람과 지금 눈앞에 온 사람 사이에서 선택한다.
- 1-9의 분노 군체 결전과 1-10 귀환은 리안의 결의를 완성하며 카이의 첫 기억 단서와 요새의 다음 원정을 연다.

### 제2장 : 세라 · 「웃음이 끝난 자리」

- 유리 정원으로 약재를 구하러 가는 원정이 세라가 고아원 아이들을 찾던 과거와 이어진다.
- 웃음으로 감췄던 약속·죄책감·군체에 대한 증오가 아이들의 흔적을 마주하며 드러난다.
- 하이델의 합류와 살아 있는 꽃, 카이·리안·미나토의 응답이 세라의 선택에 영향을 준다.
- 끝나지 않는 술래와의 작별 뒤 옛 친구 엘렌이 구조 통로를 봉쇄한다. 2-9에서 살아 있는 사람을 먼저 데리고 나가기로 결의한다.
- 2-10에서 잃어버린 노래와 남은 동료를 마주하고 등불단에 머무는 이유를 스스로 말한다.

### 제3장 : 노아 · 「침묵에 남긴 이름」

- 철종 교단의 방문과 추격 속에서 노아가 합류한다. 그림자 잔영과 강제 안식의 의미가 현재 사건을 통해 드러난다.
- 노아는 교단에서 이름을 지웠던 자신의 책임과 탈주의 이유를 말한다.
- 미나토의 위기와 동료들의 신뢰, 이름 없는 철종, 옛 친구 이브의 강제 안식 명령이 노아의 과거와 맞물린다.
- 3-9에서 자신에게 친절했던 친구를 인정하면서도 기록 말소와 강제 안식을 막는다.
- 3-10의 방 열쇠와 스스로 고른 대답은 노아가 이곳에 머무는 이유가 되고 관측소 원정으로 이어진다.

### 제4장 : 하이델 · 「멈춘 시계의 증인」

- 기억의 시계탑에서 하이델이 숫자로 다뤘던 피험자와 닫힌 출구, 혼자 돌아온 관측소 과거를 마주한다.
- 친구들의 질문과 리안·카이의 충돌을 통해 소등의 날과 기억 실험의 일부만 공개한다.
- 봉쇄된 기록과 4-9의 기록의 파수꾼 결전은 하이델이 증인을 남기고 돌아가겠다는 선택으로 이어진다.
- 귀환 후 조사를 혼자 짊어지지 않고 기록을 함께 읽는다. 태양과 카이의 전모는 뒤의 본편에 남긴다.

### 제5장 : 미나토 · 「돌아올 이름을 부르는 사람」

- 여명의 탑으로 향하는 길에서 미나토가 살리지 못한 첫 환자 유나와 이름을 모두 외우는 이유를 이야기한다.
- 다른 동료들의 결의는 미나토가 살아 있는 사람을 이름으로 부르고 구조하는 행동에 응답한다.
- 오르페의 안식, 자신도 쉬지 못하는 치유사의 죄책감, 기억을 연료로 삼을 수 있다는 단서가 한 사건으로 이어진다.
- 5-9 문턱의 파수꾼을 넘으며 동의를 지운 구조와 희생을 거부하고, 자신의 이름도 생존자 명부에 넣는다.
- 5-10에서 탑의 문을 열고 ‘수용’과 대면하며 1부가 끝난다. 태양의 최종 해결과 기억의 선택은 후속 본편으로 이어진다.

### 2부 예고 (라이브 확장)

- '태양을 다시 켜는 방법'을 둘러싼 대립과 희생
- 최종 선택: **누구의 기억을 바칠 것인가**

### 메인 스테이지의 실제 진행

1~5장에 각 10개, 총 50개 스테이지를 배치한다. 스토리 전용 25개, 전투 전용 7개, 스토리와 전투 18개다. **메인스토리의 한 장이 곧 한 캐릭터의 이야기다.** 1장 리안 → 2장 세라 → 3장 노아 → 4장 하이델 → 5장 미나토 순으로 과거·합류 이유·증오와 미련·장 결전·변화를 본편 안에서 전개한다.

각 장에서는 중심 인물과 카이·동료들이 함께 움직이며 세계관과 다음 장의 사건을 이어 간다. 별도 캐릭터 이야기 메뉴는 두지 않는다. 캐릭터 화면의 본편 이야기 버튼은 해당 인물의 메인 장으로 안내하며 기존 순차 해금 규칙을 따른다. 기록실은 완료한 메인 스테이지만 다시 읽는다.

혼합 스테이지는 전투 전 대화, 승리, 후속 대화가 끝나야 다음 구간이 열린다. 인간 로웬·엘렌·이브·오르페의 제압과 책임도 메인 진행에 포함한다. 실제 대본 610행과 편성은 [메인 장·스테이지](06_메인스토리_장과_스테이지.md)를 따른다.

## 6. 엔딩 구조 (2부 종료 기준)

| 엔딩 | 조건 | 내용 |
|---|---|---|
| **트루 엔딩 : 새벽** | 중심 인물들의 본편 결의 완료 + 핵심 선택 | 주인공이 자신의 기억을 바쳐 태양을 재점화. 잔영들은 각자의 기억을 되찾음 |
| **노멀 엔딩 : 여명** | 본편 결의와 핵심 선택 일부 충족 | 태양이 희미하게 돌아오나 소녀 중 한 명이 희생 |
| **배드 엔딩 : 영원한 밤** | 핵심 선택 실패 | 철종의 안식을 받아들임. 세계는 고요하게 종결 |

## 7. 연출 · 톤 가이드

### 7.1 분위기 원칙
1. **초반은 '침묵'이 연출이다**: 음악과 대사를 아끼고, 환경음(바람, 얼음, 숨소리)으로 몰입시킨다.
2. **절망을 과장하지 않는다**: 잔혹 묘사보다 **상실 이후의 정적**에 무게를 둔다.
3. **작은 온기를 반드시 하나 심는다**: 모든 챕터에는 식사, 손 온기, 작은 꽃 같은 '한 조각의 온기 장면'을 넣는다.
4. **희망은 대가와 함께 온다**: 빛을 얻을 때마다 무언가를 잃는 구조를 유지한다.

### 7.2 금기 사항
- 자극적 잔혹 묘사 위주의 연출 금지 (심의 및 브랜드 방향성)
- 캐릭터를 고통 소비용 도구로 사용하지 않기
- 미성년자 캐릭터의 성적 대상화 금지
- 무조건적 비극 반복 금지 (희망과 카타르시스 필수)

### 7.3 반복 모티프
| 모티프 | 의미 |
|---|---|
| 등불 / 불꽃 | 기억, 생명, 의지 |
| 종소리 | 애도 / 끝의 예고 (철종 교단), 후반엔 새벽의 종 |
| 유리 | 부서지기 쉬운 마음, 투명한 진실 |
| 얼음 → 물 → 꽃 | 정지된 슬픔이 녹아 흐르는 과정 |
| 별 | 되찾아야 할 미래 |

## 8. 대사 샘플

### 프롤로그 — 리안과의 첫 만남
```
[암전. 바람 소리]

리안 : …움직이지 마. 그림자가 소리에 반응해.

카이 : (숨을 삼킨다)

리안 : 살아 있는 사람을 본 건 오랜만이네.
       …그 불, 아직 꺼지지 않았구나.

[등불이 희미하게 번쩍인다]

리안 : (작게) …따뜻해.
```

### 제1장 — 첫 식사
```
세라 : 자자, 다 같이 먹자! 오늘은 특별히 통조림 두 개야!
미나토 : …그거 유통기한이 삼 년 지났는데요.
세라 : 영양은 변함없어! 아마도!
리안 : (말없이 한 입 먹고) …나쁘지 않아.
세라 : 오! 리안이 웃었다!
리안 : …안 웃었어.
```

### 제5장 — 결의
```
카이 : 기억이 없어도, 지금 여기 있는 건 진짜야.
리안 : …그래. 그거면 됐어.
       (처음으로 옅게 미소 짓는다)
       가자, 등불지기. 새벽을 보러.
```

## 9. 캐릭터 서사와 메인 장의 관계

리안·세라·노아의 이전 독립편은 시나리오 참고 자료로 보관한다. 게임의 현재 대본은 메인 장·스테이지 JSON 한 곳에서 내보낸다. 하이델·미나토도 기존 4·5장의 중심 인물로 정리했으며 별도의 개인편으로 분리하지 않는다.

| 메인 장 | 중심 인물 | 장에서 풀어 가는 갈등 |
|---|---|---|
| 1 | 리안 | 돌아오지 않는 가족을 기다리는 의무에서 살아 돌아오는 사람을 지키는 선택으로 |
| 2 | 세라 | 웃음 뒤의 죄책감과 아이들의 상실에서 현재의 구조와 옛 친구에 맞서는 결의로 |
| 3 | 노아 | 이름을 지운 책임과 교단의 명령에서 스스로 고르는 대답으로 |
| 4 | 하이델 | 관측소에서 혼자 살아남은 침묵에서 기록을 함께 읽고 증언하는 선택으로 |
| 5 | 미나토 | 살리지 못한 이름과 자신을 소모하는 구조에서 동의·휴식·살아 있는 이름을 지키는 선택으로 |

## 10. 연계 게임 시스템 요약

| 스토리 요소 | 게임 시스템 연결 |
|---|---|
| 기억을 잃는 잔영의 대가 | '기억의 파편' 재화, 스킬 사용 시 서브 대사 |
| 등불지기의 힘 / 등불 해방 | 전투의 **빛실 연결(연광 전투)** 과 '등불 게이지' — 주인공이 잔영들의 빛을 실로 이어 조율한다는 설정을 그대로 조작으로 구현 |
| 요새 재건 = 빛의 회복 | 거점 시설 확장 + UI 색감 변화 |

| 어둠도 | 전투 중 조명이 어두워지고 점화 판정이 까다로워짐 → 절망의 체감, 정화 시 다시 밝아지는 '빛의 회복' 연출 |
| 캐릭터 중심의 메인 장 | 순차 스테이지·장 결전·음악 큐·완료 대화 재감상 |
