# 레퀴엠 랜턴 · 개발 시작 버전

기획서와 스토리 설정집을 바탕으로 만든 Unity 2D 플레이 프로토타입입니다. 5개 장·50개 스테이지의 메인 캠페인, 정신력과 불꽃 점화, 2연승 맞불, 동기화로 여는 3스킬, 보상·복구·저장을 연결했습니다.

## 바로 실행

**Unity Hub에서 추가할 폴더는 `RequiemLantern/`입니다.** 전체 경로는 `D:\Project\레퀴엠 랜턴 (Requiem Lantern)\RequiemLantern`입니다. 저장소 최상위 폴더를 추가하면 게임 자산이 없는 빈 프로젝트가 열립니다.

PowerShell에서 `./Open-Unity.ps1`을 실행하면 올바른 Unity 프로젝트와 `Assets/Scenes/Main.unity`를 함께 엽니다. 에디터 상단의 Play를 누르면 게임이 시작됩니다. 기본 씬에는 카메라와 조명이 있으며 게임 UI는 Play 시 스크립트가 생성합니다.

타이틀은 저장 상태와 관계없이 **화면을 클릭해 시작 / CLICK TO START**로 표시합니다. 화면 클릭이나 Enter·Space로 시작하며, 처음에는 도입 이야기, 기존 진행이 있으면 등대 요새로 이동합니다. 설정은 별도 버튼으로 열고 진행 기록은 자동으로 유지합니다.

메인 캠페인은 [장·스테이지 대본](기획서/06_메인스토리_장과_스테이지.md)에 정리했습니다. 690행의 대화와 스토리25개·전투7개·혼합18개 스테이지를 Unity와 브라우저에 연결했습니다. 귀항호의 항해도에서 진행하고 기록실에서 완료한 이야기를 다시 읽습니다. 전투 승리 후 대화가 있는 구간은 후속 대화까지 마쳐야 다음 스테이지가 열립니다.

### 로컬 플레이 프리뷰

프로젝트 루트에서 PowerShell로 실행합니다.

```powershell
.\Start-Preview.ps1
```

브라우저에서 <http://127.0.0.1:8127/>가 열립니다. 현재 PC의 .NET 10 SDK를 사용합니다. 외부 서버나 계정은 필요하지 않습니다. 전투 계산은 Unity 프로젝트와 **동일한 C# Core 소스**를 사용합니다. 브라우저 화면은 검수용 별도 구현이며, Unity WebGL 빌드는 아닙니다.

현재 프리뷰는 **PC 마우스·키보드 기준**입니다. 모바일 터치 타깃, 세이프 에어리어, 실제 기기 성능은 후속 검증 대상입니다.

### Windows 게임

`Builds/Windows/RequiemLantern.exe`를 실행합니다. 같은 폴더의 데이터와 DLL이 필요하므로 전달할 때는 `Builds/Windows` 폴더 전체를 복사합니다.

### Unity

1. Unity Hub에서 `RequiemLantern` 폴더를 추가합니다.
2. **Unity 6000.6.0f1**, URP 2D로 엽니다.
3. `Assets/Scenes/Main.unity`를 열고 Play를 누릅니다.
4. `Requiem Lantern → Prepare Project`로 프로젝트 설정을 맞출 수 있습니다.
5. `Requiem Lantern → Build Windows Preview`로 Windows 빌드를 생성합니다.

`Open-Unity.ps1`도 제공합니다. 2026-10-02에는 라이선스 인증, 프로젝트 임포트, Windows 개발 빌드를 실제 Unity에서 통과했습니다. 설치된 Unity·UGUI·URP 참조 어셈블리만 사용하는 빠른 소스 컴파일 검사도 제공합니다.

## 캐릭터 중심의 메인스토리

**한 캐릭터의 이야기가 메인스토리 한 장입니다.** 1장 리안 → 2장 세라 → 3장 노아 → 4장 하이델 → 5장 미나토 순으로 과거와 현재의 사건을 이어 갑니다. 각 장에서 동료들이 함께 대화하고, 그 인물의 갈등을 해결하는 과정에서 카이의 여정과 세계의 비밀도 드러납니다.

스토리는 작전실의 메인 스테이지에서 진행합니다. 캐릭터 화면의 ‘본편 이야기’는 해당 인물의 장으로 안내하며, 기록실에서는 완료한 메인 대화를 다시 읽습니다. 이전 독립편 JSON·Markdown은 개발 참고 자료로만 보관합니다. 게임에 별도의 캐릭터 이야기 화면과 대본 카탈로그를 두지 않습니다.

## 4인 파티와 전투용 SD 캐릭터

파티 정원은 **4명**입니다. 기본 지급은 **리안 ★5 한 명과 미나토·하이델·마레 ★4 세 명**입니다. 실제 캠페인은 보유한 인물의 저장 편성으로 출격하며, 추가로 얻은 동료를 캐릭터 상세에서 편성할 수 있습니다. 이야기 속 합류와 소유는 별개이므로 미보유 인물의 본편도 진행할 수 있습니다.

리안·세라·미나토·노아·하이델·카이·마레에 전투 전용 **SD 6포즈 시트**를 추가했습니다. 전장 몸 높이는 Unity 기준 220px이며, 대기부터 공격·피격까지 같은 작은 SD 그림을 사용합니다. 메인·캐릭터·대화 화면과 하단 초상은 기존 원화를 사용합니다. 4인 전투에서는 하단에 후보 카드 8장과 턴에 따라 열리는 행동칸을 함께 표시합니다.

## 픽업 소환과 테스트 쿠폰

거점의 **잔영 소환**에서 리안·세라·노아 픽업을 선택합니다. 1회 별가루 160개, 10회 1,600개이며 기본 ★5 확률은 0.8%입니다. ★5 중 픽업 50%, 나머지 두 명은 각각 25%입니다. **80회 이내 ★5 확정**, 비픽업 ★5를 얻으면 **다음 ★5는 픽업 확정**입니다. 배너를 바꾸거나 재시작해도 천장·확정 상태가 이어집니다.

거점 **설정 → 테스트 쿠폰**에서 다음 코드를 저장당 한 번씩 입력할 수 있습니다.

| 코드 | 지급 |
|---|---|
| `LANTERN-TEST-9999999` | 별가루·코인 각각 9,999,999개 |
| `LANTERN-MATERIALS` | 등불 조각·기억의 파편·캐릭터 조각 각각 9,999,999개 |

획득 결과는 보유·편성과 함께 저장합니다. 중복은 ★4 조각 20개, ★5 조각 100개로 바뀝니다. 이전 모집 저장은 클리어·성장·재화·소유·편성을 보존하고 새 ★4 마레만 한 번 지급합니다. 카이는 기존 보유·사용을 유지하며 신규 소환 풀에서는 제외합니다. [규칙과 저장 이관 상세](기획서/08_픽업_모집_보유편성_테스트쿠폰.md).

## 여러 적과 공격 표적 예고

일반 스테이지에는 **적 2~3명**, 첫 단독 튜토리얼과 보스전에는 **적 1명**을 배치합니다. 적마다 체력·부위·균열·정신력·공격 예고를 따로 관리하고 모두 쓰러뜨려야 승리합니다. 작전실 카드에서 출현 적 수를 확인할 수 있습니다.

예고 카드에는 **공격하는 적 번호와 공격받을 동료 이름**을 표시합니다. 적①이 리안을 노릴 때 세라의 공격 카드를 그 예고에 연결하면 **세라가 리안 대신 맞불**을 겁니다. 표적 표시와 예고선도 세라로 바뀝니다. 이기면 그 공격을 막고 적①을 때리며, 단일 공격의 맞불을 지면 리안 대신 세라가 맞습니다. 광역 공격의 패배는 기존처럼 전체 아군에게 적용됩니다.

빈 행동칸과 불씨로 연결하며 추가 속도 조건은 없습니다. 적 몸체·부위에 연결하면 일반 공격, 적의 **공격 예고 카드**에 연결하면 맞불입니다. 상세 규칙은 [전투 개편 규칙](기획서/07_정신력_불꽃_맞불_동기화.md)을 참고합니다.

보스는 4인 편성에서 **1턴 4개 → 2턴 5개 → 3턴부터 6개**의 공격을 예고합니다. 3인 편성은 **3 → 4 → 5개**입니다. 부위를 파괴하면 그 부위에 연결된 여러 행동을 함께 차단할 수 있습니다. 광역 공격을 여러 개 추가하는 대신 표적이 분산된 단일 공격을 늘렸습니다.

적 예고는 **불 아이콘 중심의 가로 타일**로 표시합니다. 원래 표적과 대신 맞불하는 동료는 항상 보이며, 마우스를 올리면 위력·정신력·점등 확률·속도·부위·특수 효과와 맞불 예측을 자세히 확인할 수 있습니다.

## 스킬 선택과 전투 연출

첫 턴에는 각 캐릭터가 **행동 1개**를 사용합니다. 새 턴마다 파티 배치 순서대로 한 명의 두 번째 행동이 열립니다. 일반전은 최종적으로 `2·2·2·2`, 보스전은 `2·2·1·1`까지 사용합니다.

| 턴 | 일반전: 1~4번 | 보스전: 1~4번 |
|---|---|---|
| 1 | 1·1·1·1 | 1·1·1·1 |
| 2 | 2·1·1·1 | 2·1·1·1 |
| 3 | 2·2·1·1 | 2·2·1·1 |
| 4 | 2·2·2·1 | 2·2·1·1 |
| 5 이후 | 2·2·2·2 | 2·2·1·1 |

**3스킬도 행동 1개**를 사용합니다. 동기화와 불씨 비용은 유지합니다. 보스전의 3·4번 캐릭터도 제시된3스킬을 사용할 수 있습니다. 잠긴 행동칸에는 개방 턴이나 보스전 제한을 표시하며, 편성 순서는 동료가 쓰러져도 바뀌지 않습니다.

캐릭터마다 **1스킬3장·2스킬2장**, 동기화하면 **3스킬1장**을 더한 덱을 사용합니다. 매 턴 후보 **두 장을 모두 새로 추첨**합니다. 사용하지 않은 이전 카드도 턴이 바뀔 때 버리고, 남은 덱에서 새 두 장을 뽑습니다. 덱이 부족하면 버린 카드를 섞습니다. 같은 스킬이 다시 나올 수 있지만 이전 카드를 그대로 보존하지는 않습니다. 방어·회피·반격은 별도로 항상 선택할 수 있습니다.

두 장은 선택 후보입니다. 행동이 한 개일 때 다른 후보를 고르면 그 행동의 예약을 바꿉니다. 방어·회피·반격도 사용 가능한 행동 한 개를 차지합니다.

하단에는 모든 아군의 제시 카드 두 장과 초상·체력·정신력·행동칸을 함께 표시합니다. 카드를 누르면 해당 캐릭터가 선택되고, 카드에서 대상으로 바로 드래그해 연결할 수 있습니다. 새 카드는 빈 행동칸을 사용하고, 이미 연결한 카드는 자기 행동칸을 다시 편집합니다. 행동칸을 먼저 누르면 해당 칸의 스킬을 바꿀 수 있습니다. 카드에는 스킬 번호·이름·불 개수·위력 범위·불씨 비용을 표시하고, 연결 대상과 실행 버튼도 같은 하단 영역에 둡니다.

작전실에는 완료한 구간과 다음 스테이지까지만 표시합니다. 1-3 완료 후에는 1-1~1-4가 보입니다. 점화 결과를 하나씩 공개하고 접전에서는 짧게 뜸을 들이며, 리안의 묵직한 타격·세라의 되돌아 베기 등 스킬 동작을 보강했습니다.

## 전투 실행 화면과 귀항호 항해도

후보 카드 2장과 남은 행동 수를 구분해 표시합니다. 카드의 ‘2번 칸 배정’은 사용할 행동칸의 번호입니다. 매 턴 미사용 카드를 포함해 두 장 모두 새로 뽑는다는 안내도 제공합니다.

빛실을 실행하면 하단 스킬 바를 내려 전장을 드러냅니다. 맞붙는 두 인물과 효과를 확대하고, 준비·접촉·짧은 타격 정지·반동을 이어 재생합니다. 이동 중에는 인물의 이름과 현재 HP가 따라가고, 원래 위치의 이름표는 흐리게 표시합니다. 중앙 점화판은 진영별 색으로 위력을 각자의 불 옆에 보여 줍니다. 다음 계획 턴에는 스킬 바와 이름표가 돌아옵니다. 취소·화면 이동과 움직임 간소화도 지원합니다.

등대 아래의 보급선을 개조한 **귀항호**를 이동 거점으로 삼습니다. 등대는 귀환 거점으로 남고, 배는 연안의 기항지와 상륙 원정을 잇습니다. 항해도의 원형 기항지를 선택하면 해당 임무의 동료·종류·적 수를 확인하고 진입합니다. 완료한 항구의 기억도 다시 읽을 수 있습니다. 거리·의무실·시계탑 같은 내륙 스테이지는 정박 뒤의 상륙 동선입니다. 배의 이름과 귀환 신호는 2-1 도입의 동료 대화에 추가했습니다.

## 전투 효과음

맞불의 금속 충돌 ‘챙’, 베기 접촉, 일반 타격 ‘퍽’, 강한 방패·괴물 타격 ‘쿵’을 나눴습니다. 바람·장비 고정·불씨·파괴를 포함한 8종에 각 3변형, 총 24개의 원본 PCM WAV를 Unity와 브라우저가 함께 사용합니다. 전투의 주파수 변화음과 단음은 교체했습니다.

접촉음은 무기가 닿는 순간 한 번 재생하며, 같은 소리를 반복하지 않도록 변형을 순환합니다. 음소거와 화면 취소는 남은 전투음을 멈춥니다. 미리 읽지 못한 소리는 늦게 재생하지 않고 해당 순간을 건너뜁니다. 동시에 겹치는 소리의 수와 합산 볼륨도 제한합니다.

[소리 설명과 재생성 방법](Art/Audio/README.md) · [약 7초 미리듣기](Art/Audio/combat-audition.wav). 모든 소리는 직접 작성한 코드로 생성한 원본이며 외부 녹음과 음원 팩을 사용하지 않았습니다.

## 근접 전투 애니메이션

- 아군 7명의 SD 시트와 분노의 기존 시트에서 6개 전투 자세를 연결합니다. 대기 → 준비 → 휘두르기 → 타격 후 동작 → 복귀, 피격 자세를 별도로 사용합니다.
- 공격자가 상대에게 접근하고, 맞불에서는 양쪽이 함께 무기를 휘두릅니다. 접촉 순간 잠깐 멈춘 뒤 피격 반동과 복귀를 재생합니다.
- 공격 광선은 제거했습니다. 검 궤적과 불꽃은 무기가 닿는 좁은 영역에만 표시하며, 연결 안내와 치유에는 빛 표현을 유지합니다.
- 바람을 가르는 소리, 금속 충돌음, 둔탁한 피격음을 나눴습니다. 효과음 설정을 따릅니다.
- 피해는 무기가 닿는 순간 한 번만 반영합니다. 동률 맞불은 충돌하되 체력을 줄이지 않습니다.
- 움직임 간소화에서는 이동·흔들림·충돌 섬광을 생략하고 자세 변화와 체력 정보를 표시합니다.

아군 7명과 분노의 전투는 투명 PNG의 **6포즈 애니메이션**과 이동을 조합한 버전입니다. 인간 적은 전용 일러스트의 이동·기울임·반동을 사용합니다. 세부 관절을 연속으로 움직이는 Spine/Live2D 리깅은 후속 작업입니다. 포즈 제작 기록은 `Art/Combat/`, 게임용 이미지는 `RequiemLantern/Assets/Resources/Combat/`에서 관리합니다.

## 화면·스토리 개선

- 참고 이미지의 금속 테두리, 금빛 호버, 적갈색 눌림, 회색 비활성 버튼을 반영했습니다.
- 대화창에 장소 표지와 반투명 하단 패널을 적용했습니다. 내레이션과 발화자를 구분하고, 대기 중인 인물의 밝기를 낮춥니다.
- 드래그 중 연결 가능한 대상 표시, 가까운 대상 흡착, 흐르는 빛실, 연결 순간 점등을 추가했습니다.
- 실행 중 전장을 유지하며 공격 이동, 맞불 충돌, 타격·피해 숫자, 치유·호위, 부위 파괴·균열을 재생합니다.
- 체력은 실제 피해·치유 이벤트 순서대로 표시하며, 연출 종료 후 전투 상태와 맞춥니다.
- 움직임을 줄이면 흔들림·이동·파편을 간소화합니다. 수동 점화는 카운트다운으로도 진행할 수 있습니다.

메인 스토리는 장마다 중심 인물의 갈등과 동료들의 합류·식사·원정 준비·의견 충돌을 함께 다룹니다. 로웬·엘렌·이브와의 재회 및 인간 보스전도 각 장의 흐름 안에 배치했습니다. 보스 패턴은 초기 공통 패턴을 사용하며 고유 페이즈와 실제 BGM 음원 연결은 후속 작업입니다.

## 조작

정신력은 0에서 시작해 -20~+20이며 점화 확률은 10~90%입니다. 매 맞불에서 불·어둠을 다시 켜고 전체 위력을 비교합니다. 번갈아 이기면 충돌을 이어가고, 한쪽이 두 번 연속 이긴 뒤에만 실제 타격합니다. 동률은 연승을 초기화합니다. 기존 속성 상성과 유불리 예측은 유지합니다.

리안·세라·미나토·하이델·노아는 각각 1·2·3스킬과 방어·회피·반격 중 하나를 갖습니다. 잔영 기록에서 등불 조각 10개로 동기화 1을 열면 3스킬을 사용할 수 있습니다. 동기화는 레벨과 별도로 저장합니다. 자세한 초기 수치는 [전투 개편 규칙](기획서/07_정신력_불꽃_맞불_동기화.md)을 참고합니다.

- [메인 캠페인 대본](기획서/06_메인스토리_장과_스테이지.md)
- [보관용 이전 서사 초안](기획서/03_캐릭터스토리_리안_세라_노아.md)
- [가사 없는 Suno 보스 BGM 프롬프트 9종](기획서/04_Suno_엔딩보스_BGM_프롬프트.md)
- [인간 적대 세력과 관계 서사](기획서/05_인간_적대세력과_관계서사.md)
- 메인 대본 JSON: `기획서/메인스토리/campaign.json`. `Tools/compile-campaign.py`로 공용 C# 대본과 Markdown을 함께 갱신합니다. 이전 캐릭터별 초안은 서사 참고용 Markdown만 내보내며 게임에 연결하지 않습니다.

- 스토리: 대화창 클릭 또는 Space. 현재까지 표시된 글자만 담은 전체 대화 기록, 장면 내 좌우 유지, 주요 침묵의 자동 대기와 실제 전환 안내를 지원합니다. 기록 열기·앱 포커스 이탈 시 타이핑과 자동 진행을 멈춥니다. 수동 진행과 장면 넘기기는 지연하지 않습니다.
- 전투: 하단의 원하는 캐릭터 카드 선택 → 예고선·적 부위·아군 클릭. 카드에서 대상으로 바로 드래그할 수도 있습니다. 특정 행동을 바꾸려면 행동칸을 먼저 선택합니다.
- 적 예고선에 공격 스킬 연결: 맞불. 다른 동료를 노리는 공격에도 대신 맞불을 걸 수 있습니다. 팔·핵·본체: 공격. 치유·호위 스킬: 아군을 대상으로 선택.
- **AI 제안 → 빛실 실행**으로 첫 라운드를 시작하기 쉽습니다.
- 수동 연결 버튼을 눌러 오토를 켜면 다음 라운드도 자동 진행합니다.
- 설정의 점화 보조를 끄면 공격 스킬마다 수축 링이 나옵니다. 두 원이 겹칠 때 클릭/Space.
- 일반 전투 첫 승리: 코인 40, 등불 조각 2. 보스 첫 승리: 코인 120, 등불 조각 10, 기억의 파편 1. 재클리어에는 첫 보상을 중복 지급하지 않습니다. 스토리 전용과 다시 읽기는 보상이 없습니다.
- 거점의 등대 복구: 100코인으로 2단계, 200코인으로 3단계.

## 검증 명령

```powershell
dotnet run --project Tests/CoreTests.csproj
dotnet run --project Tests/CampaignTests.csproj
node Tests/preview-regression.cjs
node Tests/combat-fx-regression.cjs
node Tests/combat-audio-regression.cjs
python Tools/generate-combat-audio.py --check
.\Tools\check-unity-source.ps1
```

프리뷰 호스트를 빌드한 뒤 `python Tests/preview-api-regression.py`로 격리 저장·8129 포트에서 실제 HTTP 진행 규칙을 검사할 수 있습니다. 기존8127 플레이에는 영향을 주지 않습니다.

Windows 빌드를 실행할 때 `--smoke --capture-dir "절대경로"`를 전달하면 별도 저장 파일로 27개 화면, 캠페인 해금·후속 대화·재감상, 첫 라운드의 충돌·준비·접촉·반동 포즈, 접촉 순간 피해 적용, 체력 동기화, 승리와 보상 저장을 검사합니다. 실패하면 `smoke-result.txt`에 원인을 기록하고 종료 코드 1을 반환합니다.

진행 저장 위치: 브라우저는 `PreviewHost/.local/progress.xml`, Unity는 `Application.persistentDataPath/progress.xml`. 두 실행 환경의 진행 파일은 별도입니다.

## 아트 출처

로웬·엘렌·이브·인간 경비병의 신규 PNG는 기본 imagegen 도구로 생성해 `RequiemLantern/Assets/Resources/Art/`에 저장했습니다. 프롬프트와 제작 기록은 [campaign-human-prompts.json](Art/Characters/campaign-human-prompts.json)에 보관했습니다. 이브는 배경 제거 편집을 거친 컷아웃을 사용합니다.

기존 `이미지/` 원화를 기준으로 imagegen 기본 도구에서 배경을 분리하고, 폐허·등대 내부 배경과 분노 개체를 제작했습니다. 원본은 보존했습니다. 제작 프롬프트와 검수 제한은 `Art/Production/` 및 캐릭터/Figma README에 있습니다. Unity에는 가독성을 위해 Noto Sans KR의 굵기 400 고정본을 포함했습니다. `Tools/instantiate-font.py`로 원본 가변 글꼴에서 재생성할 수 있습니다. Noto Sans KR는 [Google Fonts 공식 저장소](https://github.com/google/fonts/tree/main/ofl/notosanskr)의 OFL 글꼴이며 라이선스를 함께 보관했습니다.
